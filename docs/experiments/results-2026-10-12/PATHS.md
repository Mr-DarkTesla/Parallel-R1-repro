# Переносимые пути в архиве

В JSON, YAML, CSV, Markdown и исторических исходниках абсолютные пути конкретных
машин заменены placeholders. Структура каталогов экспериментов, имена моделей,
checkpoint/step, названия данных и hashes сохранены.

| Placeholder | Назначение |
|---|---|
| `${PROJECT_ROOT}` | Корень checkout проекта |
| `${SHARED_ROOT}` | Корень общего хранилища, если ссылка ведёт за пределы проекта |
| `${MODEL_ROOT}` | Временный каталог моделей и checkpoint |
| `${SHM_ROOT}` | Корень shared-memory scratch |
| `${USER_HOME}` | Домашний каталог пользователя на машине исполнения |
| `${DATA_SOURCE_ROOT}` | Каталог исходных входных файлов |
| `${TMPDIR}` | Временный каталог |
| `${CUDA_HOME}` | Установка CUDA |
| `${NVIDIA_ROOT}` | Системные библиотеки NVIDIA |
| `${PYTHON_PREFIX}` | Установка Python/окружение |
| `${REMOTE_SSH_ALIAS}` | Настроенный SSH alias машины с общим диском |
| `${LOCAL_ENDPOINT}` | Локальный временный endpoint с индивидуальным URL |

Идентификаторы allocation представлены стабильными `RUN_<opaque-id>` aliases;
суффиксы rank сохраняют привязку к узлу. Это идентификаторы наблюдений в отчёте,
а не адреса действующих задач.

Placeholder в историческом исходнике или конфигурации — строка шаблона.
Перед использованием рецепта подставьте пути своей среды. В архиве нет таблицы
обратного соответствия внутренним путям; `${PROJECT_ROOT}` одинаков для
локальных и серверных ссылок на один и тот же проект.

Преобразование касается строк и ключей объектов JSON. Числовые метрики,
GPU/batch/steps, sampling, optimizer, reward coefficients и hashes входных данных
сохранены. `source_sha256` относится к первоначально считанным байтам;
`sha256` — к нормализованному артефакту. Inputs графиков и `SHA256SUMS` обновлены
для опубликованного содержимого.
