# Парный набор 0.6B из проверенных reasoning-траекторий

Статус 11 октября 2026: набор собран на CPU, обучение ещё не началось.
Целевая модель для обеих ветвей одна: post-trained `Qwen/Qwen3-0.6B` с
десятью по-разному инициализированными спецтокенами Multiverse.

Положительные ответы содержат один пронумерованный блок внутри `<think>`.
Исходники: 367 решений Claude M1, 34 проверенных решения Qwen3-4B и 46
решений Qwen3-4B после полного независимого смыслового просмотра. Для
последних 46: 32 сохранены без правки, 14 исправлены другим автором;
каждый итоговый ответ прочитан целиком. Подробный отсев, проверка ответа
и утечек: [M1](DATASET_M1_REWRAPPED367.md),
[4B-34](DATASET_QWEN4B_REWRITE34.md),
[4B-46](DATASET_QWEN4B_CLEAN46.md). Новые 46 ID и текста условий не
пересекаются со старой смесью, валидацией и fixed40.

Всего 447 различных положительных задач: 439 train, восемь val.
В train 1489 строк с блоками: старые M1 по три копии и 4B-34 по четыре,
новые 4B-46 по шесть. Ещё 588 строк собственного верного thinking и
582 строки собственного верного no-thinking Qwen3-0.6B, обе группы
сохраняют прежний повтор. Итого 2659 train и 50 val в каждом плече.
Дополнительные копии 4B-46 повышают долю полностью проверенных новых
траекторий: 276/2659 train-строк. Это повтор данных, не 276 новых задач.

Плечи `tagged` и `plain` совпадают по порядку, тексту задач, словам и
числам ответов, режиму thinking и val. В `plain` удалены только теги;
инструкции в запросе одинаковые. Грамматика, нумерация и положение
блока, непересечение текстов train/val/fixed40 и парность проверены
непосредственно сборщиком. Ответы и качество путей наследуют полные
проверки исходных наборов; сборщик их повторно не оценивает.
Максимум train 3838, val 3513 токенов при лимите 4096. Длины взяты
из проверок исходных неизменённых строк с тем же 0.6B токенизатором.

Сборка:

```bash
uv run --offline --no-project --with pandas --with pyarrow python scripts/exp21/prepare_q06_distill447_pair.py
```

Результат: `data/q06_distill447_{tagged,plain}_{train,val}.parquet` и
`audit/q06_distill447_pair_report.json`. Рецепт GPU:
`scripts/exp21/run_q06_distill447_pair_pod.sh`. Оба плеча стартуют из
одной 0.6B модели, 128 шагов, lr `3e-6`, множитель lr строк тегов 100,
глобальный пакет 32. Чекпоинты 16/32/64/96/128 оцениваются на том же
fixed40 с маской независимых путей. Выбор по dev; frozen только для
лучшего варианта. Это новый опыт, его метрик пока нет.
