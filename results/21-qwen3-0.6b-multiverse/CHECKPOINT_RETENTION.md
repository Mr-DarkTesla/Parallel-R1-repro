# Сохранение пяти чекпоинтов

10 октября 2026, после пилота selective v3. Под «чекпоинтом» здесь
понимается экспорт BF16 весов с конфигурацией и токенизатором для
загрузки модели. Текущий SFT-скрипт сохранял только финальные веса
каждого запуска, а временное состояние оптимизатора удалял после
экспорта. Промежуточных весов шагов 1–63 у законченных запусков нет.

Пять экспортов ниже **уже находятся на нашем постоянном томе**,
не в `/tmp`. Перед остановкой A у каждого проверено наличие
`config.json` и одного файла весов `*.safetensors` или `*.bin`;
размер каждого каталога около 1,2 ГиБ. Эти пять путей защищены от
очистки до завершения сравнения:

| Кандидат | Постоянный путь на нашем PVC | Основание сохранить |
| --- | --- | --- |
| M1, основной результат | `/work/runs/exp21-m1/model` | Полный dev, IFEval и frozen; исходная опорная SFT-модель. |
| Sol187 с внутренними блоками | `/work/runs/exp21-sol-th187/model` | Полный dev и IFEval; парный контроль и масочный пилот. |
| M1 two-path tagweighted | `/work/exp21/models/m1-twopath-tagweighted` | Отдельный проверенный режим повышения веса тегов; масочный пилот. |
| Sol deep75 | `/work/runs/exp21-sol-deep75/model` | Полный dev/IFEval и масочный пилот; сравнение доли размеченных данных. |
| Контроль Sol187 без тегов | `/work/runs/exp21-sol-th187-control/model` | Нужен для парного сравнения с Sol187 на тех же текстах. |

Шестой экспорт `/work/runs/exp21-sol-deep75-control/model` также
сохранён и не удалялся. Базовая модель Qwen3-0.6B на `/work/assets`
не считается обученным чекпоинтом. Таблица фиксирует защищённый
набор, а не доказанный рейтинг пяти моделей по единому числу:
полный dev, масочный пилот и смысловое качество блока измерялись
разными протоколами. Для следующего кандидата решение о вытеснении
принимать по dev-точности вместе с долей **полезных** независимых
блоков; синтаксическую долю отдельно, как диагностическую.
Пока критерий ранжирования не закреплён, существующие экспорты
не удалять.

Selective v1 и v2 были отклонены после пилотов; их экспорты
остались только во временном `/tmp` и исчезли при прежних
остановках pod. Selective v3 имел 14/40 верных ответов и 1/40
полезных блоков, поэтому в защищённую пятёрку не вошёл.
Его рецепт, журнал и сырые ответы сохранены в
[`SELECTIVE_BLOCKS_V3_RUN.md`](SELECTIVE_BLOCKS_V3_RUN.md);
временный экспорт исчез при остановке A.

На собственном PVC перед остановкой A было **1,5 ГиБ свободно из
196 ГиБ**. Этого недостаточно для безопасного накопления ещё пяти
экспортов по 1,2 ГиБ и промежуточных состояний обучения.
Следующий SFT можно запускать на временном диске, но перед
остановкой pod следует выделить достаточно постоянного места и
сохранить каждый прошедший отбор экспорт. Не считать модель
сохранённой, пока на постоянном томе не проверены конфигурация,
токенизатор и файл весов. Том и чужие данные не удалять ради места.
