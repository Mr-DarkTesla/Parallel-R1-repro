# Парный Deep51 SFT: план и статус

11 октября 2026. [Проверенный набор](DATASET_DEEP51_PAIR.md): два train-файла
по 256 одинаковых задач в одинаковом порядке. Они отличаются только
целевыми ответами для 51 примера. Tagged сохраняет исходные
проверенные блоки внутри `<think>`; plain сохраняет оба текста путей,
но убирает разметку и служебный план. Остальные 205 строк дословно
одинаковы. Shared validation содержит 63 строки v4.

Две ветви стартуют с одного checkpoint, выбранного на фиксированном
dev-пилоте из v4 step56 и recovery8 steps 4/8 по правилу из
[журнала recovery8](SELECTIVE_BLOCKS_V4_RECOVERY8_RUN.md).
Каждая ветвь: один наш H100, один проход по 256 задачам,
8 шагов, batch 32, microbatch 4, lr `3e-6`,
`tag_lr_mult=100`, полный вес текста 1,0 и маска Multiverse.
Экспорты после шагов 4 и 8. Seed и порядок строк одинаковы;
ветви идут последовательно, на одном GPU. Команда на поде:

```bash
PARENT_STEP=v4-56 bash /work/parallel-r1/scripts/exp21/run_deep51_pair_pod.sh
```

Значение `PARENT_STEP` после выбора может быть `4`, `8` или
`v4-56`; команда выше показывает последний вариант.

Порог для продолжения по одинаковым 40 masked greedy-вопросам,
после чтения каждого начатого блока: tagged ≥30/40 верных внешних
ответов, ≥4/40 строго полезных блоков, минимум на три полезных блока
больше plain, не более двух верных ответов меньше plain или исходной
модели, ≤2/40 обрезаний и ноль тегов вне `<think>`.
Полный dev и frozen до этого порога закрыты.

Исходной моделью выбран recovery8 step8:
`/checkpoints/exp21-v4-recovery8/step_8/model`. На фиксированном
пилоте он дал 29/40 верных внешних ответов, 2/40 полезных блока и
2/40 обрезания; подробнее в [журнале](SELECTIVE_BLOCKS_V4_RECOVERY8_RUN.md).
Данные и аудит переданы на наш pod. После завершения recovery8-оценки
запущена последовательная пара:

```bash
nohup env PARENT_STEP=8 \
  bash /work/parallel-r1/scripts/exp21/run_deep51_pair_pod.sh \
  > /tmp/exp21-deep51-p8-train.log 2>&1 < /dev/null &
```

PID при запуске `19747`. Результаты будут в
`/tmp/exp21-selective-runs/exp21-deep51-{tagged,plain}-p8/`.

Обе ветви завершили по 8 шагов. Итоговая validation loss:
`0.29939` у tagged и `0.30014` у plain. Рецепты, логи и
пошаговые метрики сохранены в
[`deep51_pair_p8_train_meta.tgz`](eval_archives/deep51_pair_p8_train_meta.tgz).
Экспорты шагов 4 и 8 обеих ветвей скопированы на наш постоянный PVC:
`/checkpoints/exp21-deep51-{tagged,plain}-p8/step_{4,8}/model`.
У каждого проверены конфигурация, токенизатор и веса. Поскольку
каждая ветвь имеет только два экспортированных шага, оба временно
сохранены для оценки; `TOP_STEPS.txt` содержит `4,8`.
После копирования на томе свободно 1,7 ГиБ. Одинаковый masked greedy
пилот 40 задач запущен последовательно для шагов 8 и 4 каждой ветви
на одном GPU. Сами значения validation loss не используются для
выбора модели: решают точность и полезность блоков на пилоте.

Первым завершился tagged step8. Все 40 ответов независимо проверены
дважды: **28/40** верных внешних ответов, **11/40** полных
нумерованных блоков, только **1/40** строго полезный блок,
**5/40** обрезаний, **0/40** тегов вне `<think>`.
Автоматический `acc_robust=27/40` пропустил верный интервал
`math-test/36`; ложных плюсов не найдено. [Построчное ревью](audit/deep51_tagged_p8_step8_answer_review.md)
и [полный архив](eval_archives/deep51_tagged_p8_step8_masked_pilot.tgz)
сохранены. Этот шаг не достиг порога продолжения и пока уступает
родителю recovery8 step8: 29/40 внешних, 2/40 полезных,
2/40 обрезаний. Итоговый выбор отложен до парного сравнения.

Tagged step4 также проверен на всех 40 задачах:
**27/40** верных внешних ответов, **10/40** полных
нумерованных блоков, **1/40** строго полезный,
**6/40** обрезаний, **0/40** тегов вне `<think>`.
`acc_robust` совпал с ручным ответом. [Ревью](audit/deep51_tagged_p8_step4_answer_review.md)
и [полный архив](eval_archives/deep51_tagged_p8_step4_masked_pilot.tgz)
сохранены. Он также не достигает порога и уступает tagged step8
по точности и обрезаниям при одинаковом числе полезных блоков.
Контроль plain ещё оценивается.

Контроль plain step8 уже проверен двумя независимыми чтениями всех
40 ответов: **25/40** верных внешних, **6/40** полных нумерованных
блоков, **0/40** строго полезных, **5/40** обрезаний и ни одного
тега вне `<think>`. Поскольку обе ветви стартовали с recovery8,
контроль всё же иногда создаёт блоки; это измеренный эффект, а не
отличие входного промпта. [Ревью](audit/deep51_plain_p8_step8_answer_review.md)
и [полный архив](eval_archives/deep51_plain_p8_step8_masked_pilot.tgz)
сохранены. На тех же 40 задачах tagged step8 превосходит plain step8
по внешнему ответу на +7,5 п.п. [−7,5; +22,5] (парный 95% bootstrap-ДИ)
и по полным блокам на +12,5 п.п. [+2,5; +22,5]. Это не даёт
необходимого смыслового качества: строго полезных блоков 1 против 0.
Plain step4 ещё оценивается.
