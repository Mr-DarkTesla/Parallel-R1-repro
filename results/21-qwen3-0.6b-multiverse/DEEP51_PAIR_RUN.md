# Парный Deep51 SFT: план и статус

11 октября 2026. [Проверенный набор](DATASET_DEEP51_PAIR.md): два train-файла
по 256 одинаковых задач в одинаковом порядке. Они отличаются только
целевыми ответами для 51 примера. Tagged сохраняет исходные
проверенные блоки внутри `<think>`; plain сохраняет оба текста путей,
но убирает разметку и служебный план. Остальные 205 строк дословно
одинаковы. Shared validation содержит 63 строки v4.

Две ветви стартуют с одного checkpoint, выбранного на фиксированном
dev-пилоте из v4 step56 и recovery8 steps 4/8 по правилу из
[журнала recovery8](SELECTIVE_BLOCKS_V4_RECOVERY8_RUN.md).
Каждая ветвь: один наш H100, один проход по 256 задачам,
8 шагов, batch 32, microbatch 4, lr `3e-6`,
`tag_lr_mult=100`, полный вес текста 1,0 и маска Multiverse.
Экспорты после шагов 4 и 8. Seed и порядок строк одинаковы;
ветви идут последовательно, на одном GPU. Команда на поде:

```bash
PARENT_STEP=v4-56 bash /work/parallel-r1/scripts/exp21/run_deep51_pair_pod.sh
```

Значение `PARENT_STEP` после выбора может быть `4`, `8` или
`v4-56`; команда выше показывает последний вариант.

Порог для продолжения по одинаковым 40 masked greedy-вопросам,
после чтения каждого начатого блока: tagged ≥30/40 верных внешних
ответов, ≥4/40 строго полезных блоков, минимум на три полезных блока
больше plain, не более двух верных ответов меньше plain или исходной
модели, ≤2/40 обрезаний и ноль тегов вне `<think>`.
Полный dev и frozen до этого порога закрыты.

Исходной моделью выбран recovery8 step8:
`/checkpoints/exp21-v4-recovery8/step_8/model`. На фиксированном
пилоте он дал 29/40 верных внешних ответов, 2/40 полезных блока и
2/40 обрезания; подробнее в [журнале](SELECTIVE_BLOCKS_V4_RECOVERY8_RUN.md).
Данные и аудит переданы на наш pod. После завершения recovery8-оценки
запущена последовательная пара:

```bash
nohup env PARENT_STEP=8 \
  bash /work/parallel-r1/scripts/exp21/run_deep51_pair_pod.sh \
  > /tmp/exp21-deep51-p8-train.log 2>&1 < /dev/null &
```

PID при запуске `19747`. Результаты будут в
`/tmp/exp21-selective-runs/exp21-deep51-{tagged,plain}-p8/`.
На момент записи обучение ещё идёт; метрик генерации нет.
