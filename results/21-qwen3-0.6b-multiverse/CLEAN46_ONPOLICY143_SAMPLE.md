# Clean46: новые собственные masked-траектории

12 октября 2026. После полного dev и fresh masked holdout40 выбран
текущий лидер по содержанию блоков, Qwen3-4B clean46 tagged step32.
У него 12/40 полезных независимых блоков с верным итогом на новых
задачах против 7/40 у mixed401; этого недостаточно для цели.
Следующий этап собирает данные для отбора по качеству, **обучение
ещё не разрешено этим сбором автоматически**.

## Пул и отсев

Исходные 189 задач взяты из уже проверенного
`data/qwen4b_onpolicy189_candidates.jsonl`. Родительский аудит
`data/qwen4b_onpolicy189_candidates.audit.json` содержит 189
проверенных кандидатов, ноль блокирующих утечек, уникальные ID и
нормализованные вопросы, ноль пересечений с ранее исключёнными
train и fixed40. Из них исключены 46 ID, на которых clean46 уже
обучалась. С fresh holdout40 совпадений ни по ID, ни по тексту нет.
Остались **143 задачи: 68 GSM8K и 75 MATH**. Код:
`scripts/exp21/build_clean46_onpolicy_pool.py`, точный список и
причины: `data/clean46_onpolicy_unseen_candidates.audit.json`,
вход для генератора: `data/clean46_onpolicy_unseen_candidates.jsonl`.
Gold-ответы сохраняются для фильтра, но генератор не передаёт их
в запрос и не пишет в строку ответа.

## Запланированный одноподовый сбор

На личной одной H100 запрошены 8 независимых сэмплов на задачу,
**1144 траектории** всего. Модель clean46, temperature 0.7,
top-p 0.95, top-k 20, предел 2048 токенов для GSM8K и 4096
для MATH. Декодер использует те же маску sibling-путей и RoPE-позиции,
что в SFT и masked holdout. Промпт не содержит решение.
`run_clean46_onpolicy143_sample_pod.sh` проверяет маркер прежней
оценки, отсутствие другого GPU-процесса, модель и вход; ставит lock,
возобновляет идентичный запуск и проверяет все 1144 пары ID/seed.
Затем только на CPU запускает `filter_onpolicy_rollouts.py`:
верный финал, грамматика, расположение блока, лимит длины.
Скрипт пишет отдельные `GENERATION_DONE`, `FILTER_DONE`,
`ATTEMPT_DONE`, сырые ответы и причины отклонения.

**Критерий перед SFT:** автоматический фильтр не считает семантику.
Из provisional нужно отобрать и независимо проверить достаточно
примеров, где оба пути верны, нетривиальны, действительно независимы,
их значения не решены до блока и корректно объединены. Ориентир
для следующей пары SFT: не менее 150 качественных траекторий на
не менее 80 задачах и ручная точность фильтра не ниже 70% на 40
случайных принятых ответах. Если этот порог не достигнут, обучение
по сбору не запускается. Следующий сравнительный опыт должен иметь
равный по задачам и числу строк контроль без отбора по необходимости
путей. Новых frozen-наборов до окончательного выбора модели нет.

Прокси не используется, дополнительных подов и PVC не создаётся.
Сырые данные должны оставаться на личном `/checkpoints`, пока не
будут архивированы локально. В пределах проекта сохраняются не
более пяти постоянных моделей; сбор не создаёт модельных чекпоинтов.
