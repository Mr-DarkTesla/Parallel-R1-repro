# Двухпутевой M1 для SFT с раздельным весом целей

10 октября 2026. Источник: [367 уже проверенных M1-решений](DATASET_EXPANDED_THINKING.md), которые Claude написала сразу в Multiverse внутри `<think>`. Каждый пример ранее прошёл проверку ответа, структуры, независимости путей, утечек и ручное ревью. Новые задачи и внешние запросы для этого варианта не создавались.

Оставлены все 337 примеров с ровно двумя `<Path>`. Отброшены 30 грамматичных примеров с тремя путями: при требуемой независимости и одинаковых позициях третий путь не видит второй и не получает свой порядковый номер. Наблюдаемая ошибка прежней модели: третий путь повторяет `2:`. Содержание оставшихся решений не менялось. Восемь validation-задач исходного M1 уже были двухпутевыми; их ID сохранены, train/validation не пересекаются.

| Шаг | Различных M1-задач | Комментарий |
| --- | ---: | --- |
| Проверенный расширенный M1 | 367 | Пул очищен от пересечений с eval и полным MATH test; GSM8K dev исключён из train |
| Только два пути | 337 | 30 трёхпутевых исключены без изменения текста других строк |
| M1 в train / validation | 329 / 8 | По три копии, 987 / 24 строки |

К M1 добавлены по 300 исходно верных ответов Qwen3-0.6B в thinking и no-thinking, по три копии каждого. Получилось 2748 train и 63 validation строк. В train: 987 M1, 879 replay no-thinking, 882 replay thinking; в validation: 24, 21 и 18. Различия чисел возникают потому, что split задан по ID задачи, а не по строкам. Подготовка и проверка: `scripts/exp21/prepare_expanded_thinking_m1_two_paths.py`, [аудит состава](data/sft_expanded_th_m1_twopath_replay3_audit.json), [аудит токенов](data/m1_twopath_target_audit.json). Максимальная длина полного train-примера 3838 токенов при лимите 4096, превышений 0; 13 818 целей тегов в train, замаскированных целей тегов 0. Все 337 сохранённых M1-ответов проходят грамматику и нумерацию.

Для парного контроля подготовлены строки на тех же ID, в том же порядке и с теми же вопросами и ответами после удаления структурных тегов. Проверка соответствия прошла для train и validation; контроль затем обучен за те же 64 шага. Его результаты пилота записаны в `EXPANDED_TH_RUN.md`.

В опыте `tagweighted` все десять структурных токенов M1 получают вес loss 1, остальной текст M1 и EOS вес 0,1. Исходные ответы Qwen в replay получают вес 1 на всех своих целях. Это меняет только функцию потерь; тексты, маска внимания и позиции остаются прежними. [Проверка сдвига целей](../../scripts/exp21/check_weighted_sft_mask.py) на реальной строке подтвердила 14 целей тегов с весом 1, 350 текстовых с весом 0,1 и 348 replay-целей с весом 1.

Ограничение: набор учит ровно двум независимым путям. Произвольное число нумерованных путей требует явного сигнала номера текущей ветки; в текущей маске его нет. Качество модели определяется отдельной dev-оценкой, а не валидностью золотых данных.
