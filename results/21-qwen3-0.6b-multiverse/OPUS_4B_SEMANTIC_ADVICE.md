# Совет Opus после смыслового ревью 4B

11 октября 2026. Один запрос к Claude Opus через VK AI Proxy с краткими
агрегированными результатами 4B, без просьбы раскрыть скрытое рассуждение.
Ответ и точный запрос сохранены в `audit/opus_4b_semantic_advice_*`.
Этот вызов стоил **$0.07992** по полю `total_cost_usd`; известный нижний
предел расходов проекта теперь **$75.8358776 из $200**. Это не точный
счёт: два отказа generic proxy для DeepSeek и Qwen3-32B не вернули
`usage` или invoice.

Opus предложил собрать новые ответы самой текущей 4B с независимой
маской путей и отбирать только задачи с верным финалом, грамматикой,
разными нужными путями и без заранее вычисленного ответа до блока.
Для обучения он предложил matched control: те же задачи и объём,
но случайный выбор среди ответов, прошедших только проверку финала и
грамматики. Это способ проверить вклад смыслового отбора, а не просто
добавления собственных генераций.

Его пороги (150 траекторий на 80 задачах, ручная точность фильтра
70%, прирост полезных блоков 6/40) являются **предложением**, а не
измеренным фактом. Дорогую абляцию каждого пути нельзя считать
валидной автоматически: модель может повторить ответ из одного пути
или после пустого пути и всё равно дать тот же финал. Ручное ревью
остаётся обязательным. Сначала завершаются уже запущенные M2 и
парное 4B focus34; затем можно оценить выход собственных 4B
генераций на небольшой партии и решить, хватит ли качественных данных
для такого SFT.
