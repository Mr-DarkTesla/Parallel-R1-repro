# M1-367: проверенные решения перенесены внутрь `<think>`

Статус: **готовый парный SFT**, без новой платной разметки. Источники:
187 строк `data/pair_final_m1.jsonl` и 180 строк
`data/more_m1_matched180.jsonl`. Они получены на очищенном train-пуле,
имеют ноль пересечений друг с другом, прошли предыдущие проверки
грамматики, независимости путей, ответа, лимита длины и утечек. Состав:
140 GSM8K integer, 93 MATH integer, 71 MATH fraction, 63 MATH expression.
Исходные ревью первых 187 описаны в `DATASET_M1.md`; для новых 180 личный
просмотр 20 и независимый просмотр 30 непересекающихся строк дали 50/50
полезных блоков и 0 неверных ответов (`DATASET_M1_MORE.md`).

Конвертер `scripts/exp21/build_m1_rewrapped_sft.py` поставил `<think>`
перед исходным решением и `</think>` перед исходной строкой
`Final Answer:`. Внутри блока оставлен исходный M1-текст. 367/367
сохраняют внешний ответ дословно, реконструируют весь исходный ответ,
имеют один нумерованный `<Parallel>` внутри reasoning и проходят прямой
`math_verify`. Максимальная длина промпта с ответом 3838 токенов при
лимите 4096.

Контрольное плечо удаляет XML-теги Multiverse, оставляя сами слова,
формулы, Outline, Path и Conclusion внутри `<think>`. Плечи совпадают по
ID, порядку, промптам, режиму thinking, replay и split. На каждое плечо
2301 строк: 367 позитивов по три копии и по 300 верных собственных
thinking/no-thinking ответов Qwen по две копии. Train 2251, val 50;
по ID пересечения нет. У 21 задачи позитив и replay делят ID, но имеют
разные запросы; обе записи этого ID остаются в одном split. Этот
повторный рецепт из прежнего M1-эксперимента сохранён для сопоставимости,
и его возможное влияние проверит контроль без тегов.

Файлы: `data/m1_rewrapped_{tagged,plain}.jsonl`,
`data/sft_m1_rewrapped_{tagged,plain}_{train,val}.parquet`, полный
машинный отчёт `audit/m1_rewrapped_report.json`. Новые GPU-прогоны и
их метрики описываются отдельно; подготовка данных их не подразумевает.
