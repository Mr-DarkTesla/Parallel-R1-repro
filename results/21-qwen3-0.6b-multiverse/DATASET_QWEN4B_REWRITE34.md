# Парный набор из 34 thinking-траекторий Qwen3-4B

Статус 11 октября 2026: **допущен и включён в парный 4B mixed401 SFT**. Оба плеча
содержат те же 34 задачи в том же порядке. В plain-плече удалены только
десять структурных тегов; весь остальной текст, включая `<think>` и строку
`Final Answer:`, сохранён. Источники:
[`tagged`](data/qwen4b_rewrite_reviewed_tagged.jsonl),
[`plain`](data/qwen4b_rewrite_reviewed_plain.jsonl),
[`отчёт проверок`](audit/qwen4b_rewrite_pair_report.json).

## Источник и отсев

Все 320 условий взяты из `data/pool.jsonl`. Пул проверен
`dataset_survey/scripts/leakcheck.py` против наших eval-наборов и полного
MATH test; GSM8K dev исключён. Для 4B выбраны по 80 задач GSM8K integer,
MATH integer, MATH fraction и MATH expression, без 647 ID прежних
положительных наборов. Постобученная Qwen3-4B сгенерировала по одной
thinking-траектории. Из 320 ответов 163 верны, чисты и не обрезаны;
144 обрезаны. Два заголовка `Part 1/Part 2` найдены в 57 верных ответах,
но содержательно независимыми оказались 18. Среди остальных 106 верных
найдены ещё 18 кандидатов с двумя вычислениями внутри `<think>`.

Первый конвертер сделал 36 грамматичных блоков. Независимое чтение всех
36 признало строго полезными 25: восемь пограничных и три негодных
исключены. Затем авторы переписали ещё 33 верные 4B-траектории из того
же проверенного пула: восемь GSM8K и 25 MATH. Изменения текста здесь
разрешены; исходные внешние ответы оставлены. Первичный просмотр всех
33 принял 12, признал пограничными пять и отклонил 16. Слепое
независимое ревью сочло полезными 14, пограничными шесть и отклонило
13. Один GSM8K ответ неоднозначен из-за формулировки условия и исключён.
**В итог попали девять строк, принятых обоими проверяющими.**
Получилось 25 + 9 = **34**, порог независимого чтения 30 примеров выполнен.

Состав: 17 GSM8K и 17 MATH. Типы ответов включают целые, дроби и
выражения; полный список ID и точные источники в JSON-отчёте. Из
`replay_nt` нельзя добавлять `math-train/1514` и `math-train/424` второй
раз как независимые примеры: это пересечение исторического replay с
итоговым набором. С текущим отложенным validation нет совпадений ни по
ID, ни по нормализованным условиям.

## Примеры

`gsm8k-train/5845`: один Path вычисляет выручку $80, второй отдельно
вычисляет пожертвования $60. Conclusion складывает $140. Ни одному
пути не нужен результат другого.

`math-train/2318`: один Path выбирает позиции четырёх одинаковых букв
`A` через `C(7,4)=35`, другой переставляет оставшиеся буквы через
`3!=6`. Conclusion умножает результаты и получает 210.

`math-train/6693`: Path независимо получают сумму внутренних углов
пятиугольника 540° и сумму долей отношения 18. Conclusion находит
нужный угол 150°.
