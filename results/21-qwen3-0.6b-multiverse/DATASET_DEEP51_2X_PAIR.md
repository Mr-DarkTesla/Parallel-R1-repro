# Deep51-2x: парный набор для короткой абляции экспозиции

Набор проверяет только одну гипотезу: достаточно ли один раз показать 51
проверенный Deep51-блок модели Qwen3-0.6B. Предыдущий один проход дал
грамматичные блоки, но лишь 1 строго полезный на пилоте из 40 задач. Здесь
каждый из тех же 51 положительных примеров предъявляется дважды, без новых
текстов, внешних вызовов, расходов прокси или запуска GPU.

## Состав

Оба файла содержат 256 строк в одинаковом детерминированном порядке:

| Тип | Строк | Разных ID | Tagged | Plain |
| --- | ---: | ---: | --- | --- |
| Deep51 | 102 | 51 | исходный ответ из `accepted51.jsonl` дословно, два предъявления каждого ID | тот же текст путей без контейнера и служебного плана, также два предъявления |
| `control_th` | 45 | 45 | одинаково | одинаково |
| `replay_th` | 109 | 109 | одинаково | одинаково |
| Всего | 256 | 205 | `sft_deep51_2x_tagged_train.parquet` | `sft_deep51_2x_plain_train.parquet` |

`replay_th` выбирается без замены из прежних 160 строк recovery8, детерминированно
по `deep51-2x-replay-20261012`: 55 MATH, 34 GSM8K, 20 ARC. Контрольные 45
строк совпадают с Deep51-1x. Копии одного positive ID получают разные
`copy_index` и позиции, но одинаковые вопрос и ответ; это намеренное повторение,
поэтому число уникальных ID равно 205, а не 256.

В arms меняется только разметка 102 positive строк. Tagged копирует их
исходный ответ байт-в-байт; plain удаляет `<Parallel>`, `<Goal>`, оба
`<Outline>`, `<Conclusion>` и теги `<Path>`, оставляя оба содержательных
пути в прежнем порядке. Все 154 неположительных строки совпадают между arms.

## Проверки

Запускать из корня репозитория:

```bash
python3 -B scripts/exp21/prepare_deep51_2x_pair.py
/tmp/exp21-audit-venv/bin/python -B scripts/exp21/audit_deep51_2x_pair.py
```

Аудит останавливается при любом нарушении. Он проверяет 256 строк и общий
порядок, 102 positive строки и 51 уникальный positive ID, два предъявления
каждого, дословную tagged-трассу, эквивалентность plain-решения, ответы
против `pool.jsonl`, грамматику блоков внутри `<think>`, ноль тегов вне
`<think>`, отсутствие утечек в eval и в fixed pilot, и лимит 4096 токенов.
Результат сохраняется в `data/sft_deep51_2x_pair_quality.json`.

## Рецепт будущего сравнения

Если QA проходит, обе ветви запускаются отдельно, но с одинаковыми прежними
параметрами: один проход, 8 шагов, batch 32, microbatch 4, lr `3e-6`,
`optim.tag_lr_mult=100`, `+data.parallel_text_loss_weight=1.0` и
Multiverse-mask. Не менять одновременно loss, tag lr, базовый checkpoint или
decoder: тогда разница будет измерять увеличение экспозиции Deep51 с одного
до двух раз.

Пилот остаётся тем же fixed 40. Продолжать можно только при ручной проверке
всех начатых блоков и одновременно: tagged не менее 29/40 внешне верных,
не менее 4/40 строго полезных, минимум на 3 полезных больше matched plain,
не более 2 обрезаний и ноль тегов вне `<think>`.
