# Пересчёт структуры Parallel, 12 октября 2026

Источник: локально сохранённые `raw.jsonl`, `score_rows.jsonl` и
`block_rows.jsonl` для каждого набора с `DONE`. GPU не использовались.

```sh
python3 scripts/exp21/summarize_full_parallel_pair.py results/21-qwen3-0.6b-multiverse/eval_runs/full_parallel_greedy results/21-qwen3-0.6b-multiverse/eval_runs/full_parallel_greedy/summary_structure_20261012.json
```

Скрипт проверяет равенство числа строк, входных запросов, числа токенов
и прежнего признака полного нумерованного блока. Фактические вызовы
берёт из `raw.model_forward_calls`. Последовательную глубину считает
по полным нумерованным блокам в закрытом `<think>`; ширину — по числу
`<Path>` в них. Ответы с неправильной грамматикой получают глубину 0.

Результат: среди 3664 завершённых ответов девяти срезов каждый полный
нумерованный блок имеет ровно 2 пути; ответов с двумя такими блоками
нет. Таких ответов с одним блоком — 2958. Синтетический ответ с двумя
последовательными блоками ширины 2 и 3 успешно распознан тем же
парсером; нули не вызваны запретом таких структур в коде. `py_compile`
и `git diff --check` прошли. Средние и распределения сохранены в JSON и
`FULL_PARALLEL_PAIR_RUN.md`.
