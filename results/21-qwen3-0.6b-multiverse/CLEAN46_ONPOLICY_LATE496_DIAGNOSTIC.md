# Clean46 on-policy: независимая диагностика второй части сбора

12 октября 2026, 02:12 МСК. Текущий единственный GPU-сборщик продолжает 1144 masked-траекторий. Не дожидаясь его окончания, на CPU скопированы **первые 720 полных строк** (90 задач по 8 seed), не прерывая и не дублируя GPU-процесс. Тот же `filter_onpolicy_rollouts.py` принял предварительно 422/720 ответов по форме, длине и внешнему ответу; отклонил 298. По источникам: GSM8K 314 принято, 150 отклонено; MATH 108 принято, 148 отклонено. Основная причина отказа: 260 неверных внешних финалов. В файле [summary.json](audit/clean46_onpolicy_early720_filter/summary.json) сохранены все причины и их пересечения. Это **не** допуск к SFT: фильтр не проверяет смысл путей.

Чтобы не повторять [ранний аудит первых 224 строк](audit/clean46_onpolicy_early224_blind_review.md), отобраны только provisional с номером исходной строки **225–720**. Их 282. Из них `random.Random(21102026).sample(rows, 40)` выбрал [40 ответов без gold](audit/clean46_onpolicy_late496_blind_sample.jsonl): 27 GSM8K и 13 MATH, 29 разных задач. [Манифест](audit/clean46_onpolicy_late496_blind_manifest.json) сохраняет seed и все `(id, seed)`; [part1](audit/clean46_onpolicy_late496_blind_part1.jsonl) и [part2](audit/clean46_onpolicy_late496_blind_part2.jsonl) непересекающиеся. Два исполнителя независимо читают по 20 полных условий и ответов, не получая gold. Критерий строгий: оба Path вычисляют разные необходимые величины без видимости друг друга, Conclusion объединяет обе, финал верен. Декоративные ветки и два повторных метода одного готового ответа не засчитываются.

Этот срез **не заменяет** заранее назначенные 40 случайных provisional из полного фильтра 1144 ответов. Для итогового гейта подготовлен `scripts/exp21/sample_onpolicy_manual_gate.py`: он отказывается работать, пока `summary.json` не сообщает все 1144 траектории. Отрицательная проверка на 100-строчном раннем фильтре завершилась ожидаемым `ValueError: manual gate requires complete 1144 rollouts, got 100`. После завершения генератора и полного CPU-фильтра выборка будет создана с seed 20261012 и отдельным слепым ревью.

Выполненная CPU-команда на личном pod: `head -n 720 /checkpoints/exp21-clean46-onpolicy143/rollouts.jsonl > /tmp/exp21-onpolicy-early720.jsonl`, затем `CUDA_VISIBLE_DEVICES= /work/venv/bin/python /tmp/exp21-eval-code/scripts/exp21/filter_onpolicy_rollouts.py /tmp/exp21-onpolicy-early720.jsonl /tmp/exp21-onpolicy-early720-filter --candidates /checkpoints/exp21-clean46-onpolicy143/candidates.jsonl`. Оттуда сохранены [422 предварительных ответа](audit/clean46_onpolicy_early720_filter/provisional_candidates.jsonl) и summary; сырые 1144 ответов останутся на `/checkpoints` до полного архива. VK AI Proxy не расходовался.

## Слепой итог, 02:17 МСК

[Исполнитель 1](audit/clean46_onpolicy_late496_review_part1.md) прочитал все 20 строк своей половины: **4 зачёта, 16 отказов**. [Исполнитель 2](audit/clean46_onpolicy_late496_review_part2.md) прочитал остальные 20: **7 зачётов, 13 отказов**. Итого **11/40 = 27,5%** строго полезных блоков среди автоматически принятых ответов поздней части сбора. [Машинная сводка](audit/clean46_onpolicy_late496_blind_summary.json) хранит ID и seed всех 11 зачётов. Оба отчёта сохранены до чтения gold и содержат построчные причины. Типовые отказы: Path использует результат sibling, повторяет расчёт, подменяет исходное условие неверным фактом или переносит обязательную третью часть решения из Path в Conclusion либо за пределы блока. Три и более `Path` сами по себе допустимы; оцениваются независимость и вклад каждого. В одном спорном случае первый отчёт уточнён без смены вердикта.

Этот показатель намного ниже предварительного порога 70%, но выборка взята только из строк 225–720, а не из полного набора 1144. Поэтому он **не заменяет итоговый случайный gate40** и не даёт права преждевременно останавливать живой sampler. До итогового гейта по on-policy данным SFT не запускать. Готовые 150 проверенных авторских меток остаются отдельным источником для следующего парного SFT после освобождения GPU.
