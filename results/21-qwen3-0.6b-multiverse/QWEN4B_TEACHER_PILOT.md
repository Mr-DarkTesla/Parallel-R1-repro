# Qwen3-4B: новые thinking-траектории

Статус 11 октября 2026: **первый проход и независимое ревью завершены;
25 строк прошли строгий смысловой отсев. Ещё девять дважды проверенных
переписанных 4B-траекторий дали готовый к SFT набор из 34 строк;
в обучение он ещё не подан**. [Карточка набора](DATASET_QWEN4B_REWRITE34.md).
Используется постобученная
`/work/assets/models/Qwen3-4B`, скачанная ранее прямо на личном pod.
Новых расходов через VK AI Proxy нет.

Вход `data/qwen4b_teacher_pool320.jsonl` детерминированно выбран из
`data/pool.jsonl`, уже очищенного `dataset_survey/scripts/leakcheck.py`
от наших eval-наборов и полного MATH test. Исключены 647 ранее выбранных
ID из M1-187, M1-180, Sol203 и agent78. Выбрано по 80 задач GSM8K integer,
MATH integer, MATH fraction, MATH expression. Для каждого типа MATH взяты
60 задач уровней 1–3 и 20 остальных, чтобы получить и простой, и более
сложный материал. Ни один ID не повторяется.

План на одной H100: один свободный thinking-ответ на задачу,
`max_tokens=1536`, структурный текстовый запрос `Part 1/Part 2` без
Multiverse-тегов, температура 0.6, top-p 0.95, top-k 20.
`scripts/exp21/generate_pool.py` сохраняет полный raw-трейс;
`scripts/exp21/grade_gen.py` затем отбрасывает неверные, обрезанные и
повреждённые ответы через `math_verify`. Только после просмотра
независимости частей ответы могут стать предложениями для разметки
`<Parallel>` внутри `<think>`. Скрипт очереди и журналы:
`scripts/exp21/run_qwen4b_teacher_pilot_pod.sh`,
`/work/exp21/qwen4b_teacher/` на личном pod.

Фактический первый проход: 320/320 сырых ответов, из них 163/320
верны, чисты и не обрезаны. По типам: GSM8K integer 63/80,
MATH integer 34/80, fraction 35/80, expression 31/80. Обрезано
144/320, в основном MATH. Среди 163 верных 57 имеют оба заголовка
`Part 1:` и `Part 2:`. Независимое чтение всех 57 приняло только
**18**: 32/39 отказов были последовательными шагами, 5 тривиальными,
2 проверяли уже полученный результат. У 55/57 оба заголовка стоят
после `</think>`, у одного оба внутри и у одного по разные стороны
границы. Внешние части нельзя
использовать без переноса путей внутрь reasoning. Из оставшихся 106
верных решений без двух заголовков строгий просмотр принял ещё 18,
чьи независимые вычисления уже были внутри `<think>`. Итого 36/163
содержательно пригодных кандидатов; остальные 127 имеют зависимые,
тривиальные или повторные части. CPU-конвертер перенёс/обернул
все 36 в один нумерованный блок внутри `<think>` и проверил
грамматику, внешний ответ, `math_verify` и длину до 4096 токенов.
Личный просмотр 21 полной строки исключил две за пустую по смыслу ветвь.
Слепое независимое ревью всех 36 подтвердило 36/36 верных внешних ответов
и грамматичных блоков внутри `<think>`, но строго полезными сочло лишь
**25/36 (69,4%)**. Восемь простых разбиений пограничны, три исключены.
Поэтому все 36 нельзя направлять в обучение: порог 90% на непросеянной
выборке не пройден. Пригодные 25 выделены в
`data/qwen4b_teacher_final_{tagged,plain}.jsonl`: во втором файле удалены
только десять типов тегов, внешний текст сокращён до исходной точной
строки `Final Answer:` в обоих плечах. Автоматические проверки дали
25/25 верных ответов (`math_verify`), грамматичных блоков внутри
`<think>` и попарно одинаковых текстов без тегов; предельная длина
824 токена. Два ID совпадают со старыми `replay_nt` и должны быть удалены
из них при возможном смешивании. Сам набор из 25 ещё не покрывает
требование независимого просмотра 30 примеров для нового набора, поэтому
в SFT не подставлен. Сборщик и аудит:
`scripts/exp21/build_qwen4b_teacher_sft.py`,
`audit/qwen4b_teacher_final_{report.json,excluded.jsonl}`.

`audit/qwen4b_teacher_conversion_{accepted,rejected}.jsonl`,
