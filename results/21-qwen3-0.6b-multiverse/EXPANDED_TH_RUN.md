# Парный SFT на 367 задачах M1/M2, промежуточный журнал

10 октября 2026. Модель: post-trained `Qwen/Qwen3-0.6B`, специальные токены Multiverse с разной инициализацией. В обоих наборах один грамматичный нумерованный блок находится строго внутри `<think>`. M1 содержит решения Claude; M2 сохраняет дословные no-thinking решения Qwen, помещённые внутрь `<think>`. Это не настоящие thinking-трейсы Qwen: отдельная выборка таких трасс описана в `audit/qwen_structured_thinking/annotation_round2/README.md` и пока не использована для SFT.

Оба плеча имеют по 367 различных задач с одинаковым распределением источников и типов ответов, 2251 обучающую строку и 50 строк валидации. В каждое плечо одинаково подмешаны 300 собственных верных no-thinking и 300 thinking ответов Qwen по два раза. SFT: 64 шага, lr 1e-5, batch 32, microbatch 4, max length 4096, `+data.structure=multiverse`, `optim.tag_lr_mult=100`, один наш H100 pod `vcharkin-exp-vm-0`. Готовы обе модели, `TRAIN_PAIR_DONE`. Обучение запущено `scripts/exp21/run_expanded_thinking_sft_pod.sh`; запуск и метаданные сохранены в `runs/expanded-th-train-metadata.tgz`. Удалённый журнал оценки: `/work/exp21/expanded_th/eval_pair.log`.
