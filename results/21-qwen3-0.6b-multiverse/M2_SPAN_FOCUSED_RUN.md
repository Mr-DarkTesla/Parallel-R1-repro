# M2 0.6B: усиление CE внутри блока не помогло

11 октября 2026. Один наш H100 завершил 64 шага SFT. Все три заранее
сохранённых шага 16/32/64 оценены на одинаковых 20 GSM8K и 20 MATH:
thinking, greedy, маска независимых путей и позиции Multiverse.
Исходные 367 положительных задач и replay не менялись относительно
прежнего M2 с полным CE; изменён только вес CE для текста вне
`<Parallel>` внутри положительных ответов: 0,1 вместо 1.
[Рецепт и проверка данных](M2_SPAN_FOCUSED_QUEUE.md).

| Модель | Верные внешние ответы | Формально полные блоки внутри `<think>` | Обрезано | Токены, среднее | Идеальные форварды, среднее |
| --- | ---: | ---: | ---: | ---: | ---: |
| Прежний M2, полный CE, шаг 64 | **20/40** | 20/40 | 0/40 | 377,5 | 354,2 |
| Новый вес вне блока 0,1, шаг 16 | 9/40 | 4/40 | 13/40 | 1296,8 | 1289,2 |
| Новый вес вне блока 0,1, шаг 32 | 10/40 | 21/40 | 1/40 | 559,2 | 529,3 |
| Новый вес вне блока 0,1, шаг 64 | 16/40 | **21/40** | 1/40 | 457,2 | 430,8 |

Строки старого и нового шага 64 совпали по ID и точному входному
промпту для всех 40 задач. Разница нового шага 64 против прежнего M2:
**−10 п.п. верных ответов**, парный 95% интервал
**[−30; +10] п.п.**; по полным блокам **+2,5 п.п.**
**[−17,5; +22,5] п.п.** Интервалы получены 10 000 перевыборками
задач с seed 20261011. Небольшой пилот не доказывает точную величину
потери, но не показывает искомого выигрыша.

Независимый просмотр всех 40 ответов шага 64 нашёл **только 1/40
строго полезный независимый блок** среди 21 формально полного.
[Причины по каждой задаче](audit/m2_spanfocus_step64_semantic_review.md).
По автоматическому парсеру верно 16/40; ручной счёт 17/40,
поскольку `gsm8k-train/300` даёт правильный внешний ответ 60, но
содержит ошибку внутри пути. Модель отклонена до полного dev и
других frozen-наборов; её checkpoint не входит в пять сохраняемых
по проекту.
