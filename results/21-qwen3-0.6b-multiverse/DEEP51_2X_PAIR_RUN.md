# Парный опыт Deep51-2x: план до запуска

11 октября 2026. Проверяем один узкий вопрос: улучшится ли содержательное
качество блоков, если каждый из 51 уже проверенного Deep51-примера
показать дважды за те же восемь шагов SFT. Это 102 учебные строки,
но только 51 уникальная задача с блоком; новых задач опыт не добавляет.
Освободившиеся 51 место берём из replay. Оба плеча имеют одни и те же
256 позиций, 45 control thinking, 109 replay thinking и одинаковый
порядок задач. В tagged обе копии сохраняют проверенный ответ с
блоком, в plain обе копии сохраняют те же математические тексты без
структурной разметки. Набор допускается к запуску только после
автоматического аудита ответов, утечек, длины и парности.

Оба плеча стартуют с одного recovery8 step8 и обучаются последовательно
на одном нашем GPU. Рецепт оставлен таким же, как у Deep51-1x:
8 шагов, пакет 32, микропакет 4, seed 1, lr `3e-6`,
`optim.tag_lr_mult=100`, полный вес текста 1,0, Multiverse-маска,
одинаковая validation из 63 задач. Экспорты шагов 4 и 8 сначала
остаются во временном каталоге `/tmp/exp21-selective-runs/`;
постоянный PVC имеет только 1,7 GiB свободно. После оценки можно
перенести лишь чекпоинт, который входит в защищаемые лучшие и
помещается на собственном PVC. Старые пять v4, пять v5 и остальные
защищённые модели ради этого опыта не удалять.

Сравнение: те же 40 masked greedy-задач, ручное чтение всех начатых
блоков и внешних ответов, парные интервалы против исходной 0.6B,
родителя и matched plain. Предварительно заданный порог продолжения:
tagged ≥29/40 верных внешних ответов, ≥4/40 строго полезных
независимых блоков, минимум на три полезных блока больше plain,
≤2/40 обрезаний и ноль тегов вне `<think>`. Если хотя бы одно условие
не выполнено, не запускать полный dev, IFEval и frozen. Дублирование
положительных примеров меняет одновременно их экспозицию и долю
replay при неизменном размере набора; причинный вывод ограничен этой
конкретной заменой.

Команда на pod после аудита данных:

```bash
bash /work/parallel-r1/scripts/exp21/run_deep51_2x_pair_pod.sh
```

Аудит набора прошёл: 256 строк на arm, 205 уникальных ID,
102 размеченных предъявления, ноль утечек и превышений 4096 токенов.
Максимальная длина 3838 токенов.
[Карточка и команды воспроизведения](DATASET_DEEP51_2X_PAIR.md),
[машинный аудит](data/sft_deep51_2x_pair_quality.json).
Данные и скрипт перенесены на наш pod, QA-файл прочитан повторно,
перед запуском GPU был свободен. Парное обучение запущено одной
командой из этого файла через `nohup`, PID `25103`:

```bash
nohup bash /work/parallel-r1/scripts/exp21/run_deep51_2x_pair_pod.sh \
  > /tmp/exp21-deep51-2x-p8-train.log 2>&1 < /dev/null &
```

Обе ветви завершили 8 шагов и сохранили BF16 экспорты шагов 4 и 8
во временном каталоге pod. Итоговая validation loss: tagged
`0.29958`, plain `0.29833`. [Логи, рецепт и метрики обучения](eval_archives/deep51_2x_pair_p8_train_meta.tgz)
сохранены локально. Validation loss не используется для выбора.

После проверки обоих `DONE` и свободного GPU запущена последовательная
оценка tagged step8, plain step8, tagged step4, plain step4 на
одинаковых 40 masked greedy-задачах; PID `26707`. Результаты на pod:
`/tmp/exp21-deep51-2x-{tagged,plain}-p8-eval/step_{4,8}`.
Новые веса находятся в `/tmp`: 1,7 GiB на собственном PVC
недостаточно для безусловного сохранения всех четырёх экспортов.

Первый завершённый пилот, tagged step8: ручное чтение всех 40 ответов
дало 27/40 верных внешних ответов, 11/40 полных нумерованных блоков,
1/40 строго полезный блок, 6/40 обрезанных ответов и 0 тегов вне
`<think>`. Парсер `acc_robust` недосчитал один корректный интервал
`math-test/36`. [Сырые ответы](eval_archives/deep51_2x_tagged_p8_step8_masked_pilot.tgz)
и [ручной разбор](audit/deep51_2x_tagged_p8_step8_answer_review.md)
сохранены. Этот шаг не проходит заранее заданный порог.

Контроль plain step8: 25/40 верных внешних ответов, 8/40 полных
нумерованных блоков, 0/40 строго полезных, 2/40 обрезанных ответа,
0 тегов вне `<think>`. `acc_robust=23/40` не принял два правильных
ответа: `gsm8k-train/279` и интервал `math-test/36`.
[Сырые ответы](eval_archives/deep51_2x_plain_p8_step8_masked_pilot.tgz),
[ручной разбор](audit/deep51_2x_plain_p8_step8_answer_review.md).

Tagged step4: 27/40 верных внешних ответов, 11/40 полных
нумерованных блоков, 0/40 строго полезных, 3/40 обрезанных ответа,
0 тегов вне `<think>`. Ручная проверка исправила два ложных
отрицания парсера: `gsm8k-train/82` и `math-test/36`.
[Сырые ответы](eval_archives/deep51_2x_tagged_p8_step4_masked_pilot.tgz),
[разбор](audit/deep51_2x_tagged_p8_step4_answer_review.md).

Оценщик PID `26707` завершился после записи всех четырёх `DONE`.
Все 160 ответов проверены вручную. GPU освободился.

Контроль plain step4 после ручной проверки: 26/40 верных внешних
ответов, 8/40 полных нумерованных блоков, 0/40 строго полезных,
