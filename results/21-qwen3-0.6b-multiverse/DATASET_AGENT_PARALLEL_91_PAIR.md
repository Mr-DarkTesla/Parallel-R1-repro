# Парный SFT-набор на 91 вручную проверенной задаче

12 октября 2026. Два источника решений внутри `<think>`:

| Источник | Задач | Контроль качества |
| --- | ---: | --- |
| [Первый пилот](DATASET_AGENT_PARALLEL_PILOT20.md) | 20 | 20/20 независимое чтение, `math_verify` 20/20 |
| [Вторая партия](DATASET_AGENT_PARALLEL_WAVE76.md) | 71 из 76 | 76/76 прочитаны чужими рецензентами, два пропуска, одна неоднозначность и два конфликта gold исключены; `math_verify` 71/71 |
| **Итого** | **91** | 91/91 принятых полезных блоков и верных внешних финалов после независимого ревью |

У всех 91 задач источник уже прошёл `dataset_survey/scripts/leakcheck.py` против всех наших eval и полного MATH test; GSM8K dev исключён. Все 91 взяты из 100-вопросного структурного списка, где повторно проверены нулевые пересечения по ID и тексту с полным clean46 train, его val, fixed40 и свежим holdout40. Состав: 61 GSM8K integer; MATH: 6 integer, 11 fraction, 13 expression. Исходные черновики до просмотра gold, финалы, журналы правок и независимые отчёты сохранены в `data/` и `audit/`. [Машинный протокол гейта](audit/agent_parallel_91_review_gate.json) содержит все 91 проверенный ID, 91 полезный и ноль неверных финалов. Личный обзор 24 новых полных вопросов и ответов, включая найденную и исправленную зависимость пути, сохранён отдельно.

`scripts/exp21/build_agent_parallel_pair.py` строит два плеча из [91 принятой строки](data/agent_parallel_91_accepted.jsonl). Каждая положительная задача повторена трижды: 273 строки. К обоим плечам добавлены одинаковые 55 собственных верных thinking и 54 no-thinking replay из clean46 train, всего **382 train строки на плечо**. Сохранены те же **50 val строк на плечо** от clean46. Tagged содержит исходный Parallel-текст; plain получается только `mv_format.strip_tags`, без перестановки или перефразирования слов. ID, промпты и порядок в двух плечах одинаковы. Сборщик проверил ответы через тот же `math_verify`, грамматику одного блока внутри `<think>`, полное отсутствие тегов в plain, пересечения train/val/fixed40/holdout и лимит 4096 токенов. Максимум train 1603, val 3513 токенов по шаблону SFT.

Выходы: `data/agent_parallel91_pair/sft_{tagged,plain}_{train,val}.parquet` и [полный отчёт сборки](data/agent_parallel91_pair/sft_build_report.json), статус `ready_for_paired_sft`. Это допуск качества **данных**, не обученная модель. В 01:45 МСК файлы скопированы на собственный persistent `/checkpoints/exp21-agent-parallel/` личного pod. На нём продолжает работать прежний единственный GPU-генератор on-policy, поэтому SFT пока не запускали.

Команда локальной сборки из корня репозитория:

```bash
uv run --offline --no-project --with math-verify --with tokenizers==0.23.2 --with pandas --with pyarrow --with transformers --with jinja2 \
  python scripts/exp21/build_agent_parallel_pair.py \
  --accepted results/21-qwen3-0.6b-multiverse/data/agent_parallel_91_accepted.jsonl \
  --out-prefix results/21-qwen3-0.6b-multiverse/data/agent_parallel91_pair/sft \
  --positive-count 91 \
  --review-report results/21-qwen3-0.6b-multiverse/audit/agent_parallel_91_review_gate.json
```

Первый вызов без `transformers`, второй без `jinja2` завершились до записи выходов; итоговый третий вызов выше прошёл. На GPU runner обязан отдельно проверить фактический tokenizer родительской 4B, атомарность десяти тегов и длину шаблона на его версии библиотек. После завершения текущего сбора: парное продолжение **из одного и того же** clean46 tagged step32, по 32 шага, batch 16, lr `5e-7`, `tag_lr_mult=100`, tagged с Multiverse mask. Экспорты 8/16/32 сначала оценить на одинаковом masked fixed40 с ручной проверкой полезности и парными интервалами против родителя и plain. Сырые ответы и логи архивировать на persistent PVC; в общий TOP-5 продвигать только после ранжирования и без превышения пяти моделей. Лучший шаг затем пройти по полному dev и IFEval; frozen только для окончательного лучшего.

На собственном pod отдельно выполнен CPU-preflight по логике runner: [результат](audit/agent_parallel91_pod_preflight.json) подтверждает ровно пять моделей в глобальном реестре, родителя среди них, **10 разных атомарных специальных токенов** с ID 151669–151678 и те же максимальные длины 1603/3513 по фактическому токенизатору 4B. GPU-процесс генератора не прерывался, обучение не стартовало. Перед будущим стартом runner повторит проверку на месте.
