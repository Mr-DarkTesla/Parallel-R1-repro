# Добавочные 180 задач M1

**Источник.** Новые задачи взяты из того же [пула без выявленных утечек](DATASET_POOL.md): MATH train и GSM8K train без всех 296 GSM8K dev. Источник ответов M1: уже сохранённые генерации Claude через VK AI Proxy, сделанные непосредственно в формате Multiverse; новых авторских вызовов для этих 180 не было. ARC в этой добавке нет, поскольку исходный парный обучающий набор M1/M2 имеет только MATH и GSM8K. ID не пересекаются с прежними 187 ID M1 или 187 ID M2.

**Отсев.** Из сырых M1 и собственной генерации Qwen после исключения прежних ID, проверки грамматики, структуры путей, `math_verify`, длины ответа до 2048 токенов и запроса с ответом до 4096 токенов осталось 317 кандидатов. Claude отдельно проверил каждое математическое утверждение: 309 `clean`, 4 `error`, 4 `uncertain`. Из 309 чистых детерминированно выбраны 180 с составом: 53 GSM8K с целым ответом, 30 MATH с целым, 61 MATH с дробным и 36 MATH с выражением. Оставшиеся 129 сохранены как резерв. Максимум у выбранных: 764 токена запроса, 659 ответа, 1333 суммарно. Известная стоимость этого дополнительного аудита: **$3.672412**, неоценённых вызовов нет.

**Проверка утечек.** У всех 180 ID проверено членство в очищенном пуле и отсутствие пересечения с прежними M1/M2. Пул повторно проверялся `dataset_survey/scripts/leakcheck.py` v2 против всех eval-наборов проекта и полного MATH test, с нулём выявленных дублей и вариантов. Ограничения поиска утечек приведены в [карточке пула](DATASET_POOL.md). Машинный итог отбора и инвариантов: [JSON](audit/more_m1_180_verify.json).

**Ручное качество.** Лично прочитаны 20 стратифицированных примеров: 20/20 полезных блоков, 20/20 верных ответов. Другие 30 примеров независимо прочитаны без аудиторских вердиктов: 30/30 полезных блоков, 30/30 верных ответов, ни одной содержательной ошибки. Выборки не пересекаются. [Мой разбор](audit/more_m1_self20.md), [независимый разбор](audit/more_m1_independent30.md).

**Пример.** `gsm8k-train/31`: один путь вычисляет выручку от больших картин 960, второй от маленьких 240; заключение складывает независимые результаты, итог 1200. Другой тип, `math-train/5704`: пути по отдельности упрощают два радикала до 18 и `4√2`, заключение получает `72√2`. Полные тексты: [180 примеров](data/more_m1_180.jsonl).

Эта добавка ещё не использовалась для SFT: перед сравнением методов нужен сопоставимый качественный набор M2 на новых задачах и доступный GPU.
