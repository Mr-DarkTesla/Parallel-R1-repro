[`selective_v3_masked_pilot.tgz`](../eval_archives/selective_v3_masked_pilot.tgz):

[`selective_v2_semantic_review.md`](selective_v2_semantic_review.md):
оба Path должны вносить верные независимые части решения, а Conclusion
объединять их для ответа. Синтаксическая полнота блока сама по себе
полезность не подтверждает.

Единственный строгий успех: `math-test/9`. Пути независимо разбирают
два случая модуля, заключение выбирает `-1/8`. В 34 остальных
синтаксически верных блоках один путь повторяет другой, решает всю
задачу до объединения или содержит ошибку. `math-test/117`
обрезан внутри повторяющегося текста с незакрытыми тегами.

`acc_robust` из архива ошибочно засчитал `math-test/29`:
модель дала `b=±16`, хотя спрашивалось **наибольшее** значение `b`,
равное `16`. Поэтому сырая автоматическая доля 15/40, а проверенная
14/40. Скрипт сравнения применяет ровно эту поправку, не меняя
архив исходных ответов. `acc` даёт 14/40 без неё.
