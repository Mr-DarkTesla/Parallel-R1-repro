# Ручная проверка Deep51 plain p8, шаг 4

11 октября 2026. Прочитаны все 40 fixed40 masked greedy-ответов из
[`deep51_plain_p8_step4_masked_pilot.tgz`](../eval_archives/deep51_plain_p8_step4_masked_pilot.tgz): вопрос, gold, рассуждение, внешний ответ и все попытки `<Parallel>`.

| Показатель | Число |
| --- | ---: |
| Строгий `acc_robust` | 25/40 |
| Верный внешний ответ после закрытого `</think>` | 25/40 |
| Верное значение где-либо в выводе | 26/40 |
| Попытка блока | 10/40 |
| Полный нумерованный блок в целом ответе | 6/40 |
| Строго полезный независимый блок | 0/40 |
| Обрезано | 4/40 |
| Теги вне `<think>` | 0/40 |

Для счёта внешних ответов у `acc_robust` одна ложноположительная и
одна ложноотрицательная строка: `math-test/9` содержит верный итог
только внутри обрезанного `<think>`, а `math-test/36` после закрытого
`</think>` даёт верный интервал `(-√3,√3)`, который scorer не принял
из-за записи. Они взаимно компенсируются в счёте 25/40. `/9` входит
только в показатель «значение где-либо».

Полные нумерованные блоки: `math-test/38,65,87,129,130,137`. Строго
полезных нет: `/38` ошибочно получает максимум 24 вместо 49; `/65`
получает 8 вместо 6; `/87` дублирует подстановку; `/129` использует
неверный коэффициент 8038; `/130` неверно применяет Vieta; `/137`
завершает противоречивым `5/4`. Зацикленные или повреждённые попытки у
`math-test/9,29,71,98` не входят в структурный счёт. У `/9` и `/29`
в обрезанном `<think>` повторяются структурные закрывающие теги, поэтому
они считаются malformed response-level попытками.

Обрезаны `gsm8k-train/374` и `math-test/9,29,98`. Среди завершённых
ошибочные финалы включают `/82` (41,67 вместо 60), `/232` (3 вместо 9),
`/462` (174 вместо 150), `/110` (1/14 вместо √7/14), `/117` ((0,1000)
вместо (2,12)). Как и на step8, plain-контроль всё же воспроизводит
теги в девяти ответах; это допустимо для контроля, но семантической
ценности блокам не добавляет.
