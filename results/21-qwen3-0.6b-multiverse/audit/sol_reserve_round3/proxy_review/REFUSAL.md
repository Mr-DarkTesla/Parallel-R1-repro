# Попытка независимого просмотра через VK AI Proxy

10 октября 2026. Вызовы сделаны локально через собственный профиль `/Users/v.charkin/.claude/settings.json`; профиль не монтировался в Kubernetes. GPU не использовался. Планировалось проверить 30 уже размеченных решений независимым Claude. Вызовы остановлены до передачи всех строк: Sonnet 5.5 и Opus 5.5 вернули отказ `reasoning_extraction` на первом пакете из трёх решений. Однословная проверка соединения перед этим прошла. Повторных обходов отказа не было; файлы вердиктов отсутствуют, независимый просмотр через прокси **не состоялся**.

Из ответа CLI зафиксирована учтённая стоимость: проверка соединения $0.000912, отказ Sonnet $0.0008306, отказ Opus $0.03336; всего **$0.0351026**. Известный нижний предел общего расхода по эксперименту вырос с $75.460431 до **$75.4955336** из лимита $200. Ранние транспортные ошибки по-прежнему без цены, поэтому это нижняя граница, а не точный счёт. Секреты и полные сообщения провайдера не сохранялись.

Качество 30 строк проверяется по независимым рецензиям Sol на исходные решения, ручному просмотру корневым исполнителем и автоматическим проверкам после разметки. Отказ прокси не засчитывается как ревью.
