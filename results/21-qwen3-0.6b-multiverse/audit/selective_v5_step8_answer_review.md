# Ручная проверка ответов selective v5, шаг 8

11 октября 2026. Один и тот же masked greedy-пилот: 20 GSM8K и
20 MATH. Источник всех 40 выводов:
[`selective_v5_step8_masked_pilot.tgz`](../eval_archives/selective_v5_step8_masked_pilot.tgz).
Рецензент прочитал 40 ответов целиком; оценка `acc_robust` сохранена
отдельно от качества внешнего ответа.

| Показатель | Число |
| --- | ---: |
| `acc_robust`, строгий автоматический парсер | 6/40 |
| Закрытый `</think>` и непустой внешний ответ | 34/40 |
| Верный самостоятельный внешний ответ | 33/40 |
| Верное значение где-либо в выводе | 34/40 |
| Обрезано без `</think>` | 6/40 |
| Любой тег Multiverse, полный или полезный блок | 0/40 |
| Теги вне `<think>` | 0/40 |

Все шесть автоматических положительных результатов верны: `gsm8k-train/279`
и `math-test/9,29,87,108,110`. Из 34 завершённых внешних ответов
неверен только `gsm8k-train/232`: модель ответила `900` вместо `9`.
Остальные 33 верны по смыслу, хотя 27 из них не распознаны строгим
парсером, который требует `Final Answer:` либо `\boxed{}`.

Шесть обрезанных ответов: `gsm8k-train/82,345,374` и
`math-test/38,98,117`. Только `math-test/98` несколько раз приходит
к правильной паре `(9,11)` до обрыва, поэтому она входит в показатель
«верное значение где-либо», но не в число внешних ответов. В остальных
пяти нет законченного верного результата.

Рейтинг чекпоинтов для цели Multiverse использует верные внешние ответы,
а не совпадение с буквальной строкой `Final Answer:` и не ответ внутри
оборванного рассуждения. Пока это один из восьми шагов v5; окончательный
отбор делать после одинакового пилота и ручной проверки остальных.
