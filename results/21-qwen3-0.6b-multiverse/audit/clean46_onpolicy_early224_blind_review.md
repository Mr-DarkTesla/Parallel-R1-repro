# clean46 on-policy early224: слепой смысловой аудит

Прочитаны все 27 вопросов и полных ответов из [сохранённой выборки](clean46_onpolicy_early224_blind_sample.jsonl): один seed для каждого из 27 разных ID, 22 GSM8K и 5 MATH. Gold в файле нет; арифметика и смысл ответа проверены вручную. Во всех ответах закрыты `<think>` и `<Parallel>`, но наличие тегов не означает полезного блока.

**Зачёт:** внутри `<think>` есть как минимум два правильных, самостоятельных и полезных Path, соответствующих Outline; Conclusion действительно сводит их результаты; внешний итог верен. Повтор одного вычисления, цитирование числа из условия, зависимость от другого Path, решение до блока, незавершённый путь, ложное промежуточное утверждение и неверный внешний итог исключают зачёт. Два разных способа решения одной задачи допустимы, если они независимо считают ответ и Conclusion их сверяет. Независимая проверка дополнительной величины тоже допустима, если Conclusion использует обе величины для проверки результата.
