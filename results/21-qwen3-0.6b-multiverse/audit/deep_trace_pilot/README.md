# Пилот длинных reasoning-трейсов Sol 6.1

10 октября 2026. Это текстовый пилот без GPU и без запросов к VK AI Proxy. Предыдущие 187 размеченных ответов Sol имеют в тренировочном parquet в среднем 725 символов (медиана 721); собственные thinking replay Qwen: 2775 (медиана 1890). На специальном запросе обученная модель отвечает примерно 138–178 токенами и часто делает неверные вычисления. Гипотеза: короткие учительские решения не дают 0.6B достаточно развёрнутого примера рассуждения. Наблюдение не доказывает причинность: на поведение могли повлиять lr, смесь данных и формат запроса.

Для проверки подготовлены 20 новых задач MATH train, поровну с дробным и символьным ответом, уровни 2–4, длина вопроса не больше 800 символов. Начальный отбор seed 20261010 пересекался с информационным корпусом `math_train_replay(info)`, который сам по себе не является eval-утечкой. В окончательном отборе дополнительно исключены ID 594 собственных replay-ответов Qwen. Две слабые пары с MATH test были содержательно близки (`math-train/6722` против `math-test/4392` о площадях квадратов, `math-train/479` против `math-test/353` о высоте брошенного мяча), а третья — вариант комбинаторной задачи о клубе (`math-train/1848` против `math-test/1524`); все три исключены до написания ответов. Финальная проверка `leakcheck.py`: 0 сигналов против наших eval, 0 точных дублей или вариантов полного MATH test, 0 даже слабых сигналов к MATH test. Встреча с информационным корпусом MATH train не считается утечкой. История и точные ID — `selection_initial.json`, `selection.json`, `leakcheck_initial20.*`, `leakcheck20.*`.

Исполнитель Sol 6.1 получает только `questions_blind20.jsonl` без gold. Запрошены подробные, самодостаточные решения без Multiverse-тегов, 1000–2500 символов при необходимости, честный `unsolved` вместо догадки. Отдельный исполнитель позже разметит только естественно независимые части, сохранив источник дословно. До SFT обязательны автоматическая проверка математического ответа и всего рассуждения, ручное чтение, независимое ревью и фильтрация недекомпозируемых задач. Сам пилот в текущие модели не входит.

## Результат первого пилота

Sol 6.1 написал 20 решений в `traces_raw20.jsonl`, не видя gold; средняя длина рассуждения 942 символа, диапазон 756–1078. Автоматическая проверка через `scripts/exp21/checks.py:correct` дала 20/20 совпадений с эталоном (`auto_answer20.json`). Независимое построчное ревью подтвердило 20/20 правильных ответов и математически верных рассуждений (`review20.jsonl`). В двух задачах явно указаны необходимые обычные соглашения об независимости рождений и неотрицательном угле поворота.

Лишь 4/20 задач содержат естественные независимые вычисления. Для них второй исполнитель вставил один блок внутри `<think>`, не меняя текст рассуждения (`tagged4.jsonl`). Независимое ревью подтвердило 4/4 верных ответа, полную грамматику, дословное восстановление источника и смысловую независимость путей (`tagged4_review.jsonl`). Полный прежний автоматический gate прошёл только `math-train/6266`: в `1491` и `5580` пути короче эвристического порога 80 символов, в `7323` слово `verify` в Conclusion вызвало ложный сигнал `recheck`, хотя два пути независимы. До обучения короткие примеры надо отсеять; `7323` можно принять только с документированным исключением из эвристики. Сейчас пилот не добавлен к обучающим данным.

Чтобы не раздувать набор искусственными ветвями, составлена слепая выборка 120 новых MATH train задач (`screen120_blind.jsonl`, `screen120_selection.json`): по 40 на целый, дробный и символьный ответ, уровни 3–5, структурные признаки в вопросе, без пересечений с принятыми 187 Sol, expanded M1/M2, реальными replay Qwen и этим пилотом. Отдельный исполнитель оценивает только потенциальную декомпозицию. После его отбора нужны leakcheck, решение без gold, проверка каждого ответа и повторная независимая оценка; ни одна из этих 120 задач пока не принята.

Результат слепого скрининга: 30/120 структурных `yes`, 90 `no`; после исключений 25 основных и 2 резервных (`screen120_review.jsonl`, `screen120_review.md`). Общий `leakcheck_screen120` не обнаружил eval-утечек по автоматическому порогу, но пять слабых пар с полным MATH test были вручную признаны слишком близкими для этого эксперимента и исключены: train ID `2052`, `3758`, `501`, `3538`, `2368`. Проверка выбранных 25 отдельно дала 0 eval-утечек, 0 совпадений или вариантов полного MATH test (`leakcheck_selected25.summary.json`). Список содержит 8 целых, 8 дробных и 9 символьных ответов (`selected25_manifest.json`). Два независимых текстовых исполнителя пишут слепые решения по 13 и 12 вопросам, без GPU и прокси; принятие зависит от будущих проверок.

Оба набора решений записаны в `traces_raw25_{a,b}.jsonl`. Из 25 задач 24 математически решены; `math-train/3423` исключена как противоречивая: подстановка `x=-1` в условие даёт `f(-1)=0`, хотя кодомен исключает ноль. Сравнение финальной строки через `math_verify` подтвердило 23 из 24; оставшаяся `math-train/2326` просит букву варианта, и ответ `C` преобразован по тексту вопроса в `0.20`, после чего совпал с эталоном. Это явное преобразование и все построчные вердикты находятся в `accepted24_audit.json`; слепой текст 24 решений — в `accepted24_source_blind.jsonl`. Независимые ревью `review25_{a,b}.jsonl` подтвердили 24/24 вычисления и естественные самостоятельные части; все 25 рассуждений прочитаны координатором. Два новых исполнителя вставляют только теги и план, сохраняя текст этих 24 решений. До их проверки новые примеры не приняты в SFT.
