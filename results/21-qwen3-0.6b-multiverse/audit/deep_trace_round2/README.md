# Слепой отбор следующей партии подробных решений

10 октября 2026. Эта партия готовится **без GPU и без VK AI Proxy**; до математической проверки, независимого ревью и разметки блоков ничего из неё не входит в SFT.

Из `data/pool.jsonl` взяты задачи MATH train уровня 3–5 с вопросом длиной 130–1000 символов, без `[asy]`, со словами, указывающими на возможные составные вычисления. Исключены принятые 187 Sol, expanded M1/M2, фактические Qwen replay, первые 20 задач и прежняя слепая выборка 120. Seed предварительного отбора `20261011`: 445 вопросов (180 целых, 125 дробных, 140 символьных). `dataset_survey/scripts/leakcheck.py` не нашёл утечек против наших eval, но 18 слабых совпадений с полным MATH test исключены до просмотра исполнителями; точные ID сохранены в `screen400_manifest.json`.

После исключения и повторного перемешивания seed `20261012` оставлены 400 вопросов: 160 целых, 115 дробных, 125 символьных. Отдельный `leakcheck_screen400.summary.json` подтверждает 0 eval-утечек, 0 дублей и вариантов наших eval, 0 даже слабых пар с полным MATH test. Сопадения с информационным корпусом MATH train отмечены отдельно и не считаются eval-утечкой.

Четыре файла `screen400_{a,b,c,d}.jsonl` содержат по 100 вопросов **без эталонов**. Независимые текстовые исполнители отметили только естественную независимость двух содержательных путей и возможные дефекты условия. Они не получали `screen400_with_gold.jsonl` или eval-тексты. Получено 57 структурно подходящих задач; 5 с сомнениями в условии исключены. Sol 6.1 решил оставшиеся 52 вслепую. Независимое математическое ревью признало все решения верными, но у `math-train/6780` неверен исходный gold: правильные минимальные значения `12,18`, а в пуле указано только `18`. Этот пример исключён.

51 оставшееся решение размечено планом внутри `<think>` без переписывания исходных слов и формул. Ревью разметки сначала нашло 49/51 полезных блоков: у `math-train/7467` объединение стояло внутри второй ветви, а у `math-train/3860` части одного случая были разделены несогласованно с исходным заголовком. После исправления границ независимые проверяющие приняли 51/51. Автоматический `checks.py` после устранения ложного сигнала на заголовках `Part 1:` проверил 51/51.
