\* Единственное расхождение с парсером: `math-test/36`. Внутри
рассуждения модель записала точный интервал `(-√3,√3)`, а внешний
ответ дал `-√3, √3` без скобок. Рецензент трактует его как сокращённую
запись того же интервала. При буквальном требовании скобок счёт
внешних ответов составляет 26/40. Ложных положительных у парсера нет.

Пять полных нумерованных блоков: `math-test/65,71,87,98,137`.
У `/65` Path 1 лишь повторяет данное, а Path 2 использует обе величины;
у `/71` Path 2 зависит от `k` из Path 1; у `/87` Path 2 решает
неотносящийся к задаче случай; у `/98` объединение выбирает неверную
точку; у `/137` Path 1 не закончен, Path 2 повторяет всю работу,
внешний итог неверен. Значит, строго полезных блоков нет.

Обрезаны `gsm8k-train/232,374` и `math-test/117,129,130`; ни один
не довёл до верного законченного результата. Из других попыток:
`math-test/9` обрывает блок при верном ответе, `/29,38` вкладывают
или ломают Path, `/130` многократно повторяет начало блока.
