# Ручная проверка ответов selective v5, шаг 40

11 октября 2026. Проверены все 40 masked greedy-ответов из
[`selective_v5_step40_masked_pilot.tgz`](../eval_archives/selective_v5_step40_masked_pilot.tgz): вопрос, gold, всё рассуждение, внешний ответ и каждая попытка блока.

«Верный внешний ответ» означает самостоятельный корректный ответ после
закрытого `</think>`; префикс `Final Answer:` для этой ручной колонки не
обязателен. Математически эквивалентная запись принимается. «Полный
нумерованный блок» требует валидной разметки всего ответа и нумерации
всех его блоков. «Строго полезный» дополнительно требует двух
содержательных, верных и независимых путей, объединённых без уже
вычисленного перед блоком ответа.

| Показатель | Число |
| --- | ---: |
| Буквенный автоматический `acc` | 21/40 |
| Строгий автоматический `acc_robust` | 25/40 |
| Верный завершённый внешний ответ | 25/40 |
| Верное значение где-либо в выводе | 25/40 |
| Грамматически валидный ответ с блоком | 17/40 |
| Полный нумерованный блок в целом ответе | 15/40 |
| Строго полезный независимый блок | 1/40 |
| Обрезано без завершения | 6/40 |
| Теги вне `<think>` | 0/40 |

`acc_robust` не имеет расхождений с ручной проверкой: ни ложных
плюсов, ни ложных минусов. Буквенный `acc` пропускает четыре правильных
ответа из-за формы внешней строки: `gsm8k-train/43,260,288,653`.

Полные нумерованные блоки: `gsm8k-train/82,228`,
`math-test/9,29,36,45,51,71,87,88,93,108,110,130,137`.
У `math-test/98` и `/129` грамматика всего ответа валидна, но в каждом
есть второй блок с повторённым `Path 1` вместо `Path 2`; они не входят
в счёт полного нумерованного блока.

Единственный строго полезный блок, `math-test/36`, разделяет две
независимые корректные проверки границ: Path 1 исключает равенство
нижней границе, Path 2 находит верхнюю границу `x=±√3`, после чего
Conclusion и текст после блока дают верный открытый интервал.

Остальные валидные блоки не проходят семантический порог. `math-test/9`
уже вычисляет оба корня до блока; `/45` использует вычисление Path 1
внутри Path 2; `/88` дублирует один и тот же способ подстановки;
`/93,130,137` содержат математические ошибки; `/51` ошибочно выводит
`f^{-1}(x)=x`; `/71,87,110` повторяют одну и ту же работу или оставляют
один путь неполным. GSM-блоки `/82,228` основаны на неверных уравнениях.

Обрезаны `gsm8k-train/232,374` и
`math-test/38,103,117,129`. Во всех шести нет корректного завершённого
внешнего ответа. У `/38,103,117` блок не закрыт; у `/129` ответ обрывается
после валидных, но семантически ошибочных блоков. Независимо от
обрыва, `/129` раскрывает разность площадей неверно:
`(2009+x)^2-(2009-x)^2=8036x`, а не `8038x+x^2`.
