# Agent-authored GSM16 dataset note

Источник заданий: `data/onpolicy46_questions_only.jsonl`. Планы: `data/onpolicy46_decomp_pilot_plans.jsonl`. Файлы с gold-ответами, кандидатами и прежними rollout не открывались.

Назначено 16 GSM8K ID. Написано 16 решений, пропусков нет. Во всех решениях вычисления размещены внутри двух Path; до блока дан только план. Каждая пара ветвей считает разные необходимые величины, а Conclusion явно объединяет их и содержит внешний итог.

Самопроверка охватила структуру тегов, уникальность ID, принадлежность к GSM8K и соответствие назначенному списку. Вопрос `gsm8k-train/201` повторно проверен по формулировке: за последние две недели задана дневная, а не недельная норма.
