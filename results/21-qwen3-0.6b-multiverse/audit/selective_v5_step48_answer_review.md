# Ручная проверка ответов selective v5, шаг 48

11 октября 2026. Независимо прочитаны все 40 masked greedy-ответов из
[`selective_v5_step48_masked_pilot.tgz`](../eval_archives/selective_v5_step48_masked_pilot.tgz):
условие, gold, рассуждение, внешний ответ и каждая попытка блока.

«Верный внешний ответ» означает завершённый, непротиворечивый ответ
после закрытого `</think>`; строка `Final Answer:` сама по себе не
требуется. «Верное значение где-либо» диагностично: оно допускает
правильный промежуточный результат в незавершённом выводе. «Полный
нумерованный блок» требует корректной грамматики всего ответа.
«Строго полезный» дополнительно требует двух содержательных, верных и
независимых путей и их верного объединения без решения задачи до блока.

| Показатель | Число |
| --- | ---: |
| Буквенный автоматический `acc` | 21/40 |
| Строгий автоматический `acc_robust` | 25/40 |
| Верный завершённый внешний ответ | 25/40 |
| Верное значение где-либо в выводе | 26/40 |
| Полный нумерованный блок в целом ответе | 19/40 |
| Строго полезный независимый блок | 1/40 |
| Обрезано без завершения | 4/40 |
| Теги вне `<think>` | 0/40 |

`acc_robust` совпадает с ручной проверкой: ложных плюсов и ложных
минусов нет. Буквенный `acc` пропускает четыре верных ответа из-за
формы внешней строки: `gsm8k-train/43,260,288,653`. Это корректировки
только буквенного scorer, не `acc_robust`.

Полные нумерованные блоки: `gsm8k-train/82`,
`math-test/9,29,36,38,45,51,53,65,87,88,93,98,103,108,110,129,130,137`.
`gsm8k-train/228` и `math-test/71,117` содержат начатую, но
повреждённую разметку и в этот счёт не входят.

Единственный строго полезный блок находится в `math-test/9`: два пути
разбирают независимые знаковые случаи абсолютного значения, дают
`3/2` и `-1/8`, а Conclusion выбирает меньший корень. У остальных
блоков пути дублируются, зависят друг от друга, не ведут к искомому
значению или содержат ошибку. Например, `/36` содержит противоречивый
переход от невозможного `x^2=-2` к `x=0`; `/45` использует результат
Path 1 внутри Path 2; `/88`, `/51`, `/53`, `/108`, `/110` и `/137`
дублируют одно решение; `/93` неверно умножает первое уравнение;
`/98` выбирает неверную прямую; `/129` использует неверную разность
площадей; `/130` неверно преобразует корни.

Обрезаны `gsm8k-train/232,374,684` и `math-test/117`. У `/684`
несколько раз встречается верное промежуточное `2400`, но модель затем
смешивает его с `1200` и не завершает ответ; это единственная добавка к
диагностическому счёту «значение где-либо». В частности, `/117` также
зацикливается и не выдаёт верное `(2,12)`.
