# Fraction8: authored question-only MATH examples

Дата: 11 октября 2026.

## Источник и изоляция

Выборка сделана из leak-checked `data/onpolicy46_questions_only.jsonl`.
Файл `data/onpolicy46_candidates.jsonl` был прочитан программно только для
пар `(id, answer_type)`: выбраны восемь MATH строк с `answer_type=fraction`;
значения поля `answer` не выводились и не использовались. Четыре ранее
написанных fraction-примера исключались по ID из
`onpolicy_agent_authored_math16.jsonl` и
`onpolicy_agent_authored_math_remaining.jsonl`; фактически исключены все 34
уже написанные MATH ID, поэтому пересечений нет. Gold, прежние rollout и
кандидатные ответы не открывались для написания решений.

## Отобранные примеры

| ID | Две необходимые независимые части | Авторский ответ |
|---|---|---|
| `math-train/4030` | проекция на прямую сегмента; минимизация параметризованного сегмента | $60/13$ |
| `math-train/446` | четвёртый корень; кубический корень | $-1/12$ |
| `math-train/5843` | два cross-product | $77/3$ |
| `math-train/429` | два cross-product | $9/11$ |
| `math-train/7395` | первый cofactor; оставшиеся cofactor | $9/2$ |
| `math-train/1828` | индикатор первого кубика; индикатор второго кубика | $1/3$ |
| `math-train/3611` | полный cosecant-square sum modulo 14; его чётная подсумма | $49/4$ |
| `math-train/7044` | тождество через $a,b$; сумма квадратов $U,V$ | $124/13$ |

Все восемь блоков находятся целиком внутри `<think>`, имеют два нумерованных
`Path`, и финальный ответ идёт после закрытия `<think>`. До блока нет
вычисленного численного ответа.

## Ручная самопроверка

- 8/8: корректная вложенность тегов и один полный `<Parallel>`.
- 8/8: два пути выполняют разные необходимые вычисления, а `Conclusion` их
  объединяет.
- 8/8: внешний ответ имеет форму `Final Answer:`.
- 0 пересечений с 34 ранее написанными MATH ID.

Нужна последующая независимая сверка математических ответов с закрытым gold
перед включением в SFT.
