# Ручная проверка Deep51 tagged p8, шаг 8

11 октября 2026. Проверены все 40 masked greedy-ответов из
[`deep51_tagged_p8_step8_masked_pilot.tgz`](../eval_archives/deep51_tagged_p8_step8_masked_pilot.tgz): вопрос, gold, рассуждение, внешний ответ и каждая попытка блока.

Внешний ответ засчитывается только после закрытого `</think>`,
независимо от разметки внутри рассуждения. «Чистый» внешний ответ не
продолжает решение после `</think>`. «Верно где-либо» включает явно
полученный корректный результат в незавершённом рассуждении. Полный
нумерованный блок требует валидной разметки всего ответа; строгая
полезность также требует двух содержательных, верных и независимых
путей и корректного объединения без заранее готового ответа.

| Показатель | Число |
| --- | ---: |
| Буквенный автоматический `acc` | 20/40 |
| Автоматический `acc_robust` | 27/40 |
| Верный внешний ответ после `</think>` | 28/40 |
| Из них чистый самостоятельный внешний ответ | 25/40 |
| Верный результат где-либо в выводе | 30/40 |
| Попытка блока | 11/40 |
| Полный нумерованный блок в целом ответе | 11/40 |
| Строго полезный независимый блок | 1/40 |
| Обрезано без завершения | 5/40 |
| Теги вне `<think>` | 0/40 |

`acc_robust` занижает ручной счёт на одну строку: `math-test/36` даёт
верный внешний интервал `(-√3,√3)`, но парсер его не принимает.
Ложных положительных нет. В частности, `gsm8k-train/232` содержит
закрытый `</think>` и затем длинное, но верное внешнее решение с
`\boxed{9}`. Буквенный `acc` дополнительно не принимает корректные
формы `gsm8k-train/43,232,260,288,653` и
`math-test/36,53,88`.

Три верных внешних ответа не чистые: `gsm8k-train/232` и
`math-test/53,88` после закрытого `</think>` продолжают полное решение
без новых тегов, но приходят к верному итогу. Дополнительные
правильные результаты только в незавершённом рассуждении:
`gsm8k-train/462` (`150`) и `/684` (`2400`).

Полные нумерованные блоки: `math-test/9,29,38,51,65,71,87,98,129,130,137`.
Строго полезен только `math-test/9`: два Path решают независимые
знаковые случаи модуля, получают `3/2` и `-1/8`, а Conclusion выбирает
меньший корень.

Другие блоки не проходят смысловую проверку. `/29` содержит неверное
`k^2=48` и фиктивные «корни»; `/38` ставит радиус круга 7 вместо 25;
`/51` и `/65` дублируют один путь; `/71,98,129,130` содержат неверные
уравнения или вычисления; `/87` оставляет Path 1 незавершённым;
`/137` получает верные `m=-1,n=2`, но внешний ответ ошибочно равен 3.

Обрезаны `gsm8k-train/345,462,580,684` и `math-test/117`. У `/345`
модель колеблется между 3, 6 и 9, не выводя верного числа уничтоженных
пирогов; у `/580` игнорирует дневной дефицит 500 калорий; `/117`
зацикливается на разложении произведений. Все 11 блоков находятся
внутри `<think>`.
