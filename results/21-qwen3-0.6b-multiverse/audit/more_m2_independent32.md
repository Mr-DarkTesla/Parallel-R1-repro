# Независимое ревью всех 32 новых M2

Проверяющий получил [32 кандидата](../data/more_m2_existing_clean32.jsonl) без результатов автоматического аудита и прочитал условие, пути, заключение и ответ каждого. Его вердикт: **31/32 полезных блоков, 32/32 верных итоговых значений, 30/32 полностью чистых решений**.

Содержательная ошибка `math-train/7045`: в `Path 2` неверно раскрыто скалярное произведение, записано `3(a·b × b)` вместо `3 b·(a×b)`; то же неверное выражение повторено в `Conclusion`. `gsm8k-train/6086` даёт верный ответ, но первый путь не участвует в выводе. Оба исключены.

Три верные, но несокращённые дроби: `math-train/1905` (`21/78` вместо `7/26`), `math-train/2079` (`12/15` вместо `4/5`), `math-train/2513` (`64/128` вместо `1/2`). Они дополнительно исключены из обучающего набора по критерию качества оформления.

Оставшиеся 27 ID: `gsm8k-train/3347`, `3422`, `3708`, `4123`, `4150`, `4557`, `4737`, `5789`, `5925`, `6068`, `6442`, `665`, `669`, `7184`; `math-train/1326`, `506`, `5447`, `5830`, `6043`, `6449`, `6455`, `6693`, `6738`, `7008`, `7013`, `7102`, `7149`. Для каждого независимый проверяющий подтвердил правильность промежуточных вычислений, полезность путей и итогового ответа. Их исходные тексты находятся в [отобранном JSONL](../data/more_m2_existing_reviewed27.jsonl). Проверка выполнялась без GPU и без вызовов прокси.
