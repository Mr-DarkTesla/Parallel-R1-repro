# Ручная проверка v4 recovery8, шаг 8

11 октября 2026. Независимо прочитаны все 40 masked greedy-ответов из
[`v4_recovery8_step8_masked_pilot.tgz`](../eval_archives/v4_recovery8_step8_masked_pilot.tgz):
условие, gold, рассуждение, внешний ответ и каждая попытка `<Parallel>`.

Внешний ответ засчитывается после закрытого `</think>`. «Верное
значение где-либо» допускает только явно выведенный правильный
промежуточный итог. Полный нумерованный блок требует корректной
грамматики всего ответа. Строго полезный блок требует двух
содержательных, верных и независимых путей, верного объединения и
отсутствия готового ответа до блока.

| Показатель | Число |
| --- | ---: |
| Буквенный автоматический `acc` | 23/40 |
| Строгий автоматический `acc_robust` | 29/40 |
| Верный завершённый внешний ответ после `</think>` | 29/40 |
| Из них чистый самостоятельный внешний ответ | 29/40 |
| Верное значение где-либо в выводе | 29/40 |
| Попытка блока | 16/40 |
| Полный нумерованный блок в целом ответе | 12/40 |
| Строго полезный независимый блок | 2/40 |
| Обрезано без завершения | 2/40 |
| Теги вне `<think>` | 0/40 |

`acc_robust` совпадает с ручной проверкой: ложных плюсов и ложных
минусов нет. Буквенный `acc` имеет шесть ложных минусов из-за формы
внешней строки: `gsm8k-train/43,260,279,288,462,580`.

Полные нумерованные блоки: `gsm8k-train/653`,
`math-test/9,29,36,51,87,88,98,108,129,130,137`. Начатые, но
повреждённые блоки находятся у `math-test/38,65,71,93`; они не входят
в структурный счёт. Все попытки остаются внутри `<think>`.

Строго полезны два блока: `math-test/9` независимо разбирает два
знаковых случая уравнения с модулем и выбирает меньший корень;
`math-test/36` независимо проверяет нижнюю и верхнюю границы
неравенства и получает открытый интервал `(-√3,√3)`. Блок
`gsm8k-train/653` вычисляет независимые стоимости завтраков корректно,
но итог `17` уже полностью получен перед блоком, поэтому не засчитан.
Остальные дублируют пути, используют один путь как зависимость другого
или содержат ошибку. Например, `/51` ошибочно приравнивает
`f^{-1}(x)` к `x`, `/71` строит неверное отношение, `/98` не находит
точку вне прямой, `/129` меняет знак разности площадей, `/130` ставит
неверный знак в сумме корней, `/137` противоречит себе относительно
`n`.

Обрезаны `gsm8k-train/232` и `math-test/65`; ни один не выводит
правильный итог. Поэтому показатель «верное значение где-либо» не
выше счёта внешних ответов.

## Сопоставление с v4 step56 и recovery8 step4

| Вариант | Внешний ответ | Полный блок | Строго полезный | Обрезано |
| --- | ---: | ---: | ---: | ---: |
| v4 step56 | 27/40 | 19/40 | 2/40 (`9,36`) | 4/40 |
| recovery8 step4 | 27/40 | 14/40 | 1/40 (`9`) | 4/40 |
| recovery8 step8 | 29/40 | 12/40 | 2/40 (`9,36`) | 2/40 |

Step8 возвращает полезный блок `math-test/36`, утраченный на step4, и
даёт на два верных внешних ответа больше v4 step56 при двух меньших
обрезаниях. Однако число полных блоков ниже на семь. Порог продолжения
всё ещё не выполнен: 29/40 меньше 30/40 и два полезных блока меньше
трёх; условия по обрезаниям и тегам вне `<think>` выполнены.
