# Скрининг первых 102 teacher trajectories

## Метод

Прочитаны первые 102 записи `data/teacher_trajectory_candidates.jsonl` в исходном порядке. Рассматривались только literal question, reasoning и внешний answer: gold, rollout и иные источники не открывались.

Принятие означает: до финального объединения есть как минимум две содержательные, отдельно вычислимые части. Общий факт из условия может быть вынесен в setup, но одна Path не должна требовать вычисленный результат другой. Группировка в JSONL задаёт естественные границы исходных абзацев; `P1` и `P2` могут включать несколько абзацев, если это одна смысловая часть.

## Итог

| Вердикт | Число |
|---|---:|
| accept | 101 |
| reject | 1 |
| всего | 102 |

Отклонена только `gsm8k-train/1551`: расчёт swearing time-outs использует уже вычисленное количество food-throwing time-outs из первой части, поэтому две автономные Paths без переписывания текста не получаются.

Большая часть принятых GSM8K строк имеет простую аддитивную декомпозицию по людям, товарам или периодам. В MATH есть также корректные независимые partial products, ограничения domain, disjoint combinatorial cases и numerator/denominator counts. Это хороший кандидатный yield, но не заменяет следующий этап: проверку ответа по pool gold, теговой грамматики, сохранности текста, длины, leakcheck и независимое семантическое review.

Полный построчный протокол: `teacher_screen_first102.jsonl`.
