# Пилот самостоятельной разметки MATH: 10 задач

Источник: `/tmp/exp21-agent-pilot-math10.jsonl`, 10 разных `math-train/*` ID без gold в предоставленном файле. Результат: `../data/agent_parallel_pilot_math10.jsonl`. Работа выполнена на CPU; GPU, Kubernetes и прокси не использовались. Созданы только два согласованных файла пилота.

## Порядок и критерий

Сначала решены все 10 вопросов и записаны полные ответы в JSONL. Только после этого прочитано поле `answer` в локальном `../data/pool.jsonl` для тех же ID. Пути строились как два независимых полезных подсчёта по данным вопроса; каждый `Conclusion` использует оба результата. Финальное значение не вычислено до `<Parallel>`. Для задачи без естественного разбиения требовался бы `status: skip` и причина без тегов; таких задач в этой десятке нет. Использовано `status: accept`, `skip_reason: ""`.
