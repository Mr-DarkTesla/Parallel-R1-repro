Первый набор repaired47 был сохранён в Git до полного независимого

Ассемблер заменил 14 утверждённых ответов в 189 исходных записях,
сохранил отдельно авторство и длину новых ответов. Тот же локальный

структурно и по ответу пригодных; все 46 окончательно принятых ID в
этих 119. Парный сборщик создал по 247 train и 50 val строк, 138
положительных, 55 thinking и 54 no-thinking replay. Он проверил
совпадение текстов после удаления только тегов, непересечение вопросов
с val/fixed40, leakcheck и предел длины. Отчёт:
`audit/qwen4b_onpolicy189_clean46_pair_report.json`.

Локальные проверки и сборка: `uv run --offline --no-project --with
tokenizers==0.23.2` для ассемблера; `uv run --offline --no-project
--with math-verify` для фильтра с подгруженным из файла `math_dapo.py`;
`uv run --offline --no-project --with tokenizers==0.23.2 --with pandas
--with pyarrow` для `build_qwen4b_onpolicy189_pair.py`. Обычный
локальный `python3` не прочёл tokenizer JSON из-за несовместимой
версии `tokenizers`; повтор с закреплённой 0.23.2 прошёл. Исходный
scorer не менялся. Файлы параметров: манифесты `repair14` и `clean46`,
проверенные выходы фильтра и `clean46_pair_report.json`.

Следующий запуск после восстановления Teleport: проверить контекст
`k8s_ml_MNTINFRA_3322`, личный `vcharkin-exp-vm-0`, процессы на GPU и
маркер `/work/exp21/qwen4b_onpolicy189/EVAL_DONE`. Сначала выгрузить
все оставшиеся результаты старого парного опыта. Затем скопировать

репозитория pod. Runner ждёт старую оценку и откажется стартовать при
другом GPU-процессе. Он использует те же родители mixed401 step128,
32 шага, lr `5e-7`, `tag_lr_mult=100`, batch 16, контроль без тегов,
экспорты и masked fixed40 на шагах 8/16/32. После оценки сравнить
