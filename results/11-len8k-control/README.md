# 11: лимиты длины 8192 на старых данных (контроль к 12)

Отличие от 02: длина примера в SFT 8192 вместо 4096 (`scripts/sft_qwen3_0.6b.sh`), длина ответа в eval 8192 вместо 3000
(`scripts/eval_qwen3_0.6b.sh`), `max_tokens` в проверке тегов 8192 вместо 3000 (`scripts/check_tags.py`). Данные те же.
Запуск: `bash scripts/run_experiment.sh 11-len8k-control`.

Мотивация: эксперимент 12 добавляет в SFT длинные примеры ParaThinker, для них нужны лимиты 8192. SFT-данные GSM8K короче 4096,
поэтому SFT здесь совпадает с 02r; разница с 02r показывает только влияние лимита eval (обрезка длинных ответов на 3000).
