# Итоговые метрики SFT Qwen3-0.6B-Base по бенчмаркам

Eval авторов: их параллельный роллаут в vLLM, temperature 1.0, top_p 1.0, до 3000 токенов, один сид на эксперимент.
Колонки «Корректных блоков» и «Правильных тегов» считаются по ответам с тегами; «—» значит, что тегов не было.

Варианты:
- **Base** — Qwen3-0.6B-Base с добавленными тегами, без обучения.
- **01a** — SFT по рецепту авторов, все шесть тегов с одинаковым эмбеддингом (ветка `exp/01-sft-baseline`, `results/eval_sft_identical_tags`).
- **01** — SFT по рецепту авторов, теги инициализированы различимо (`exp/01-sft-baseline`).
- **02** — 01 + позиции промпта идут подряд (`exp/02-sft-prompt-positions`).
- **03** — 02 + loss усредняется по токенам всего батча (`exp/03-sft-token-mean`).
- **Авторы 4B** — Parallel-SFT-Unseen на Qwen3-4B-Base из таблицы авторов, для ориентира.

## Как читать

- Разница в точности между 01, 02 и 03 укладывается в шум. Одна задача AIME из 30 при mean@16 — это 3.3 пункта pass@16,
  а стандартная ошибка на MATH300 около 2.5 пункта.
- Структура тегов меняется сильно: одинаковые эмбеддинги (01a) дают 1–2% правильных тегов, различимые (01) — 64–68%,
  исправление позиций промпта (02) — 85–90%. Нормировка (03) на структуру не влияет.
