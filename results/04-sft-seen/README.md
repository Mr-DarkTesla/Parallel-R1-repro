# 04: вариант Seen (обычная causal-маска и позиции подряд)

Отличие от 02: `+data.parallel_structure=False` — ветки не изолируются маской, позиции идут подряд (вариант авторов «Seen»).
Мотивация: роллаут авторов считает summary и всё после блока обычным causal-проходом vLLM с позициями подряд; Seen совпадает с этим,
Unseen — нет. Запуск: `bash scripts/run_experiment.sh 04-sft-seen +data.parallel_structure=False`.

Результат: лучший средний результат из всех вариантов, но прирост не доказан. Парное сравнение с 02r по 1233 задачам: +0.66 пункта,
95% CI [−0.75, 2.09]; MATH300 +1.6, AMC23 +1.6, LIMO +0.3, AIME24 +0.6, AIME25 −0.4. Структура тегов не хуже: правильных тегов 88.2%,
полностью корректных ответов 79.1%. Проверка тегов в свободной генерации для финального чекпоинта не завершена (очередь остановлена).
